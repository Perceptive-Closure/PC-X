## M02.1 · exact staged audit over correlated source facts

The input has finite-domain latent variables \(X\) and a separate finite target label variable \(t\). A finite relation on \(X\cup\{t\}\) is represented by a conjunction of explicit relation tables on named scopes, and the compatible source assignments are precisely its projections on \(X\). The label \(t\) is a specified operational target on these source assignments and the input factors encode its graph exactly. Auxiliary fields, if used, have their own declared finite semantics and do not add distinctions to the original source assignments, targets or lawful answers. Factor encodings and source validity are premises of the result.

A supplied sequence of bags \(B_0,\dots,B_k\) covers all variables. Each variable is in a contiguous interval of bags. Each factor is assigned to a bag containing its scope. \(t\) is present in every bag. Write \(P_i\) for the factors assigned by stage \(i\) and \(S_i\) for those assigned strictly later. For any history \(h\) at stage \(i\), let \(R_i(h)\) be the projection to \(B_i\) of assignments satisfying \(P_i\) and all historical readback answers. Quantify disappearing variables over their declared domains. A separate public state \(z\) explicitly records the current stage \(i=i(z)\), available named finite deterministic pure queries and their nonnegative binary integer prices. The response function \(\gamma_{z,q}\) for a query is an explicit table on a named scope in \(B_i\) of legally measurable latent coordinates. It does not read \(t\) by definition. Each complete transcript is generated by a single immutable latent assignment. A reply advances to a public state \(\delta(z,q,a)\) by an explicit table. Stage may stay the same or advance. The whole public transition graph is acyclic, with a known initial state of stage \(0\). The input records every menu and price dependence on observable history through \(z\). No acquisition changes the plant or target, and the current public state carries no hidden initial information. Advancement steps, if any, are explicit commands with replies and costs. A finite audit can stop and correctly report a label only if that label is common to all assignments consistent with its full transcript. At an empty initial relation the answer is inconsistency.

**Claim.** For every such input, \((z,R_i(h))\) is an exact sufficient state for future feasible reply histories, exact possible label sets, and minimax remaining cost of uniform proper target identification. A computable \(+\infty\) value denotes inaccessibility under this dynamic interface. If \(K=\max_i\prod_{x\in B_i}|\operatorname{dom}(x)|\), a synthesis algorithm with certificates of optimum or inaccessibility has time and certificate size bounded by \(|Z|2^K\operatorname{poly}(L,K)\), where \(Z\) is the explicit public state set and \(L\) is the full input length including graph, factor/reply tables, bags, domain data and price bit lengths. This bound is independent of the numeric audit budget. It gives fixed-parameter tractability in bag cardinality and maximum domain cardinality with explicit public input. The exact posterior possible label set and any pair of opposite labels in it have checkable absence or matching completion witnesses using the same factor relation. If a singleton is reported at any feasible history, a distinct nonemptiness witness is available. A common projection without \(z\) need not have the same continuation costs or lawful queries. Moreover uniform dynamic inaccessibility need not imply an opposite-target pair indistinguishable by every legal protocol.

**Fixed intervention claim.** For any chosen set of allowed deletions of named public query occurrences \((z,q)\), evaluate minimax audit cost for each resulting keep mask. Each deletion removes a whole occurrence and its response branches, without changing any kept query's law, price, or public update. There is one shared finite expression DAG in the keep bits, using exact \(\min\), \(\max\), addition and \(+\infty\), that yields the full value for any such mask. Its size is bounded by \(|Z|2^K\operatorname{poly}(L,K)\). For every budget, its feasible input predicate is monotone. Within this intervention domain, minimal sufficient keep sets are the inclusion-minimal occurrence supports of budget-feasible proper audits. Minimal destructive deletion sets are the inclusion-minimal transversals over those supports, with the usual empty-family and empty-support meanings. Enumeration of all such sets need not satisfy the time bound for evaluating the shared DAG.

## M02.2 · correlated routing with dynamic permission and exact costs

For every \(n\ge2\) there exists a finite canonical D-35 source family with a route record \(r\in\{1,\dots,n\}\) and gate bits \(g\in\{0,1\}^n\) of Hamming weight at most one. Every admissible gate vector can occur at every route. The fixed operational target is \(1\{\kappa^{\neg\{R\}}\le1\}=1-g_r\) at the same source entry. A lawful pure audit interface exposes an exact route record at cost \(a>0\) and distinct permanent site-record envelope reads for each \(g_j\) at respective costs \(c_j\). A distinct cheaper inspection command for site \(j\) is enabled only after the exact route read returns \(j\), at price \(s>0\) where \(s\le \min_j c_j\). All reads and the cheap permission leave the plant and target unchanged. There is no single callable command that automatically returns the gate at an unknown addressed site. Static acquisition means a fixed sequence of actual query commands legal on every resulting transcript, with the report computed afterwards. Adaptive acquisition can choose any lawful common command at its observed history.

**Claim.** Uniform worst-case static cost is \(a+\sum_{j=1}^n c_j\), and uniform worst-case adaptive cost is \(a+s\). These costs concern the operational threshold rather than full contract identity. Each route and permanent site-record read has separate independent operational content. The gap is unbounded at fixed positive unit-scale prices as \(n\) grows.

## M02.3 · matched noisy target and operational full identity

For every \(d\ge1\) there exists a finite canonical D-35 source family with \(d\) binary independent fact slots \(x_0,\dots,x_{d-1}\), every bit vector admissible, one common source entry, and the same declared registry across the family. The pure audit instruments each measure a particular installed record \(x_i\), without revealing another parameter or mutating the deployment plant. One fixed target is \(1\{\kappa^{\neg\{R\}}\le1\}=x_0\), and the same-entry A-freeze value is \(2+d+\sum_{i=0}^{d-1}2^i x_i\). Hence varying any one omitted fact changes operational behavior and full fact identity is equivalent to identity of this declared family of realized source contracts. In the noiseless certain case, both adaptive and nonadaptive worst-path optimum costs are one for the target and \(d\) for full identity with unit-price queries.

For the noisy case, each call to any chosen slot instrument returns \(x_i\) through a binary symmetric channel with fixed known \(0<\eta<1/2\). Response noises are mutually independent, independent of the fixed record values and of auditor randomness. Every instrument can be called repeatedly at unit price, and the initial transcript is uninformative. Fix \(0<\delta\le1/8\). Policies may adapt and randomize, must stop almost surely for each completion, and must be correct with probability at least \(1-\delta\) on each completion. Define worst expected cost as the maximum expected number of calls over completions, and worst-path cost as a uniform almost-sure bound on the number of calls over completions.

**Claim.** For both the worst expected and worst-path criteria, target identification optimum is \(\Theta_\eta(\log(1/\delta))\) and full identity optimum is \(\Theta_\eta(d\log(d/\delta))\), with constants depending only on \(\eta\). These statements use the same legitimate menu and uniform confidence requirement for both target and identity. No assertion is made about correlated noise, zero-error identification with positive noise, or a split between target and identity acquisition in the matched X05 experiment.

## M02.4 · exact complexity boundaries for succinct acquisition

**Pair boundary.** Finite Boolean-circuit input for the compatible class predicate and the target graph, with the exact target a circuit function of the finite latent record, makes existence of an opposite-target pair NP-complete even with a known compatible witness, no queries, and with the target realized as the same-entry R-freeze budget threshold of a finite typed one-step source description. Consequently zero-query point identification is coNP-complete on the nonempty input family. The source description permits bounded Boolean circuit guards or postconditions.

**Dynamic policy boundary.** Consider a different representation whose finite latent data are polynomial-length Boolean vectors satisfying a given circuit. A finite acyclic public acquisition interface is represented by Boolean circuits on the public registers and a finite explicit list of named commands, with deterministic latent readback circuits, history update circuits using only public registers, commands and replies, nonnegative binary integer prices and a unary bound \(H\) on the number of calls. A depth counter enforces the bound and can serve as an acyclic rank. The initial register is fixed, the target is an exact circuit function of the latent data, and the input class is nonempty. Uniform proper identification within a given binary budget is PSPACE-complete, even with unit prices, a product class of latent bits, and a target which is one fixed operational R-freeze threshold bit. This claim is about succinct public registers, not the explicit public size in M02.1. The accepted binary-budget SUBSET SUM obstruction for a static opposed-score oracle remains a separate prior boundary.
