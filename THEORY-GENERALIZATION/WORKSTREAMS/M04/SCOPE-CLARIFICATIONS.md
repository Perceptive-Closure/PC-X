# M04 scope clarification · Fixed label before initialization

In [M04.1](STATEMENTS.md), a pure responder rooted in a completion fixes a single independently defined deployment label before any chance initialization of the audit record. The initial chance law may be informative, but its draw does not change that fixed label. Impose every class-specific loss row over all such pure responder choices, as in the proof. Private mixtures within one fixed label preserve the same bounds by linearity. When the responder privately mixes plans across labels, conditioning on a positive-probability label is itself a mixture of the corresponding pure rows, so the class guarantee is preserved.

A single pure responder that induces genuinely mixed deployment labels through chance is a different input. Zero-masking by the label then bounds joint failure and label probability together. For example, if initialization yields PASS with probability 1/10 and the test always says FAIL, the PASS-masked error is 1/10 but the error conditional on PASS is 1. An explicit chance-mixed-label extension would need constraints of the form Pr(failure and label k)≤b_k Pr(label k) for each relevant modeled response mechanism. Neither that extension nor an audit-dependent definition of the label is used in the sealed result. [Proof](PROOF.md)
