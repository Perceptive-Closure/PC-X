## Constructing the mass representation

Fix a mode, deployment run d and context x. Write w for its deployment occupancy, a_y for Σ_b q_yb, and s_y for the mass-scaled outcome probability in the reference row. These variables have sums Σ_y a_y=Σ_y s_y=w. On w>0, the pair (a/w,s/w) consists of normalized probability vectors. Multiplying the reference row constraint by w gives Hs≤hw. Since the total variation distance of finite probability rows is half the sum of their coordinatewise absolute differences, its bound is equivalent to the existence of t_y with

    0 ≤ t_y ≤ 1,   −t_y ≤ a_y − s_y ≤ t_y,   Σ_y t_y ≤ 2δw.

For necessity choose t_y=|a_y−s_y|, which is at most w≤1. Conversely these inequalities imply Σ_y|a_y−s_y|≤2δw. When w=0, nonnegativity and the sums force q,a,s=0, so the conditional restrictions leave the unspecified null rows free. This extension never divides by a zero occupancy. Likewise on a_y>0, the actual deployment event probability conditional on that outcome letter is q_y1/a_y. The lower and upper event constraints are exactly ℓ_ya_y≤q_y1≤u_ya_y. When a_y=0, q_y1=0 and these constraints hold automatically.

The same equivalence holds simultaneously at all cells and all modes because every additional joint condition is imposed on the original lifted coordinates. The supports, row identities, nonnegativity, normalizations, and any specified compact bounds on auxiliary coordinates are closed linear constraints. Together they give a bounded closed polyhedron per mode. There are no products of unknown probabilities in this representation. For a general finite physical representation supply operational witnesses for every feasible projected array. For an outer representation the actual completion satisfies the mass constraints, and feasible relaxed extremizers certify sharpness only over the relaxation.

A realization for one special case illustrates the premise. Fix a deterministic lawful observation-history controller, define each outcome letter by a complete trace compatible with that controller and the source transition supports, and permit arbitrary initial finite environment tickets selecting such traces within each declared context. The environment follows the ticket when the prescribed legitimate actions occur. At each public node the fixed controller sees only its recorded prefix and takes its own prescribed action. Define the independently enrolled terminal rule on the concrete trace labels, which can include an installed parameter or a machine event. Sampling a ticket according to the corresponding mass row realizes any admitted trace weights exactly. Completing specified off-policy rows is a separate source obligation. Alternatively, for an explicitly represented full finite execution tree and fixed stochastic controller, let f(h) denote the marginals of terminal-leaf masses at a concrete prefix h. At every policy node impose f(ha)=f(h)π(a|o(h)) for its certified policy kernel and the authorized observation o(h), with noncallable branches assigned zero. On a positive-mass chance node use its child-to-parent mass ratios, checking any primitive constraints on those ratios. This constructs the stipulated trajectory law by induction. Further structural restrictions across chance rows or different runs require their own compatible lifting constraints and realizability argument.

The conditional bridge deals with an outcome row at its genuine intended setting. Estimating surface responses after a different policy, unauthorized reset, or trajectory-dependent filter does not supply that bridge by itself. Selecting a coarse outcome letter is valid insofar as its physical event probability and the local laws are the ones the inequalities constrain. A trusted event contract can specify that scoring physically takes place while leaving some means or which mode is installed uncertain.

## Risk, endpoint attainment and transporter comparison

For a completion in mode m the total law in run d gives r_d=Σ_{x,y}q_{dxy1}. This is a linear function on the feasible mass array. A finite maximum of these functions is continuous. On a nonempty compact mode its minimum and maximum are attained. A line segment joining any minimizing and maximizing points is feasible, and the intermediate value property along the segment shows that the entire interval between them occurs. The same argument works when the two points agree, giving a singleton. A finite union of modes can leave holes in the image.

For the minimum solve the linear program with the additional variable t∈[0,1] and inequalities t≥r_d for every d. For every z the least admissible t is R(z). For the maximum, max_z max_d r_d(z)=max_d max_z r_d(z) because both maxima range over the same pairs (z,d). To check the FAIL side against a threshold τ, maximize each r_d; a strict value above τ yields that completion as a witnessed FAIL. A maximizing equality alone is a PASS boundary whenever the other coordinates are at most τ at that witness. To check PASS feasibility add all r_d≤τ and run feasibility. These checks apply to a subset of anchor facts or a mode-and-response tuple by intersecting its closed constraints first. The classification conditions follow from the attained interval endpoints. A mixed class supplies two genuine threshold witnesses in the exact representation, since some completion has R≤τ and another has R>τ. A class empty of feasible arrays is inconsistent.

T18's source-verified local factor argument supplies a useful subclass. For a paired condition x, use complete canonical histories as y, the common trusted scoring map b=V(y), and let μ_x be the independently derived common path submeasure from the accepted T18 proof. If the relevant exact row is the reference deployment paired under the common policy, include s_y≥wμ_x(y) and a_y≥wμ_x(y). Both normalized rows then dominate μ_x when w>0. Summing event and nonevent coordinates gives the accepted interval [μ_x(V=1),1−μ_x(V=0)] and TV≤1−|μ_x|. This is a representation of consequences of the verified factors, with any further factor coupling retained only if represented. M03 also accepts a bridge checked directly for an outcome abstraction, independently anchored interval-valued event semantics, and contextual mixture constraints. Exact equivalence of the two trajectory laws is unnecessary for a target threshold certificate.

For T20 set δ=1 and release reference/event bounds on unsupported cells, except for any independent restrictions on permitted support. With fixed context weights and separate interval bounds for covered cells, summation gives the T20 lower and upper formulas. If uncovered mass is free to receive both event labels holding the supported rows and weights fixed, complete its event probability with 0 and 1, respectively. The two risks differ by exactly that unseen mass. If the roster includes concentration on this context, the latter world has worst risk one. When constraints couple the cells or multiple runs, solving the common LP preserves those constraints. Taking a separate minimum in each coordinate could construct an infeasible vector and give an incorrect lower bound for the exact minimum of the maximum.

## Finite calibration and actual membership

For each registered probability cell i, let its n_i draws be independent Bernoulli indicators with the designated true mean p_i. Hoeffding's two tails give Pr(|p̂_i−p_i|>ρ_i)≤2exp(−2n_iρ_i²)=α/K. For a categorical trial, each coordinate is individually such an indicator even though the coordinate indicators of the same trial are dependent. Union bounding gives simultaneous coverage for the whole finite family. On this event a bridge |γ_D−γ_E|≤η gives |γ_D−p̂_E|≤ρ_i+η and clipping is valid because γ_D∈[0,1]. A true reference outcome row constrained by its covered coordinates satisfies the corresponding normalized row inequalities. The same logic applies to justified calibrations of inventory weights or other primitive probabilities. A certified outward rational enlargement keeps the true cell in its interval.

The claim is about membership after dynamic selection from one registered family. Conceptually define the full vector of potential registered batches, including unused ones, with the stated marginal batch guarantees, then intersect their individual good events. A rule chooses which outputs to inspect, and on this intersection every used constraint contains the same actual completion provided the operational premises hold. Finite shared data are allowed if each batch premise remains valid. An adaptive measurement design that changes a cell's conditional distribution or number of trials requires its own simultaneous validity argument. The freeze, intervention fidelity, deployed regime, support, approved controller, event provenance and repertoire of allowed semantic modes are independent prerequisites. An estimate's fit neither verifies those prerequisites nor bounds the failure probability of invalid provenance. A report of INCONSISTENT can flag an incompatibility, but on the coverage event a valid true completion rules out an empty class.

Consequently any rule issuing only when the selected class is homogeneous has probability of a wrong issued label at most α, without conditioning on issuance. It can abstain often. At the true threshold a fixed noisy calibration can offer two-sided uncertainty at every available precision, so a finite decisive deadline needs additional justification. The confidence calculation also does not certify that a legal implementation could deliver every mathematical adversarial example. Exact operational witness construction is checked separately.

## Minimum sufficient facts for a realized record

Let Q_m be the base feasible polytope in mode m. Fix the joint vector of realized facts with a common satisfying completion. For an anchor subset J, its compatible class is the union of Q_m∩⋂_{i∈J}F_{i,m}. This class is nonempty because any completion satisfying the full record also satisfies this subset. Let z range over the completions opposing the proposed label. For such z, it survives observing J exactly when it satisfies every selected fact, equivalently J∩D(z)=∅. Thus J is sufficient exactly when it hits every attained violation pattern. The proof includes the no-opposite case, where the empty set certifies, and D(z)=∅, where even the full catalog is insufficient for the proposed label.

The finite algorithm starts with an empty collection of patterns. Choose a minimum-cost hitting set for the collected patterns, taking a fixed tie rule if desired. For a PASS claim, search all modes and runs for an LP witness with r_d>τ after the selected facts. For a FAIL claim, test whether some mode admits all r_d≤τ after those facts. If the search returns a witness, evaluate each fact at the witnessed mode and mass array to produce D(z); it is disjoint from J. If the pattern is empty, report infeasibility with that witness. Otherwise it is new, because J hits every earlier pattern. Add it and repeat. Each nonempty pattern eliminates the current hitting set and only finitely many distinct patterns exist. When the LP checks find no opposing completion, J is feasible for the full problem and minimum cost by its optimality against a subcollection of all necessary hitting constraints. An optimal solution certifies only the named target and can leave internal quantities, law and mode uncertain.

With rational numbers, each separation pass uses at most |M||D| linear programs for PASS, or |M| for FAIL. A tight primal witness and an LP dual or feasibility certificate can verify the resulting comparisons exactly. The number of passes is at most 2^{m_a}+1, and the weighted Boolean hitting step can enumerate all 2^{m_a} subsets if no integer solver is available. A retrospective certificate is not a prospective measurement invitation when its facts are unrevealed. A polynomial bound for general minimum-anchor selection would in particular solve weighted hitting set. To see the reduction, assign one base singleton mode to each nonempty edge E of an arbitrary finite incidence hypergraph and assign that mode risk 1. Include a safe mode with risk 0. Give query i a registered realized fact that keeps the safe mode and precisely the edge modes with i not in E. A genuine read of installed bit i can implement this mode-dependent fact by assigning that bit to 1 iff i is in the mode's edge and to 0 in the safe mode, where all realized facts are zeros. The opposing violation pattern of the edge mode is exactly E. Each mode can separately use a constant deterministic, independently recorded terminal event. A weighted anchor certificate at τ in [0,1) has exactly the given weighted hitting-set cost.

## Prospective deterministic strategies

Before any read, fix the compatible relation between full response tuples, modes, and feasible deployment arrays. Every base completion must have a possible tuple. Facts supplied by single reads may permit more arrays than their joint response constraints. At each transcript, retain the complete possibilities consistent with its observed entries. The retained arrays are a union of compact polytopes, one for every consistent mode and full tuple. Nonempty branches are precisely those with at least one such witness. Their label sets are computed by the preceding threshold tests.

Induct on the number of unread items. If the current class is nonempty and homogeneous, stopping at zero cost is feasible and minimal by nonnegative prices. A mixed terminal without reads cannot issue an exact common label. At a nonterminal mixed state, any admissible deterministic strategy must read some remaining i. In each feasible response branch its continuation must solve that same subproblem, with one fewer unread item and all the same hidden-completion/response consistency constraints. Its worst branch cost is at least c_i plus the maximum child optimum. Conversely take a minimizing read and a minimizing child strategy in every feasible branch, which exist by the induction hypothesis whenever the displayed value is finite. This tree attains that value, and if all remaining choices have infinite value the mixed state cannot be resolved. The adversary can be understood as having fixed a completion and tuple initially. Every path of feasible responses corresponds to a single consistent full tuple and array.

For outcome alphabets A_i there are at most ∏_i(1+|A_i|) partial assignments, storing one value and action per state. Eligibility in the sealed class depends on having left the read unused. Branch count, array LP count per state, and exact verification depend on the explicitly given mode/tuple description. Exponentially many tuples or partial assignments may be needed. For a constant-price exact direct read available unchanged at every state, taking it at the root costs d_0. Any tree using it on a reachable branch has worst supported cost at least d_0 by nonnegativity. A tree avoiding it on every reachable branch is semantic-only, and costs at least W. The two root choices and this lower bound give min(d_0,W). Expected cost and finite fixed-confidence comparison would use a specific observation law, confidence requirement, and error cost on the same eligible population.

## Qualification of the result

All exact extrema, threshold witnesses and cost claims apply inside the admitted operational class. Whole-action authority, actual callable lifts, policy records and separately owned trusted scores preserve the D-35 separation between predictive compatibility and authorized use. The class allows stateful finite trajectories and independent checked bridges. Arbitrary unknown policy-dependent dynamics, overlap-free causal extrapolation, data-dependent construction of the true semantic class, and arbitrary disruptions remain outside this proof.
