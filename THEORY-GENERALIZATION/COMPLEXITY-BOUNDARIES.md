# Complexity and cost boundaries

| Problem and encoding | Established result |
| --- | --- |
| Bounded typed source construction | Enumerating the finitely constrained holes and bounded state graph gives sound complete checking of the declared family. Intermediate beliefs and latent valuations can be exponentially numerous. An unrestricted looping source has an undecidability reduction. |
| Exact staged deterministic acquisition | Retain \((z,R)\) with explicated public register \(z\) and projected separator relation \(R\). For \(K=\max_i\prod_{x\in B_i}\lvert\operatorname{dom}x\rvert\), the shared-state certificate and computation use \(\lvert Z\rvert 2^K\operatorname{poly}(L,K)\), with full input \(L\) and exact prices. Factored explicit bags give parameter tractability in bag size and domain size. Unfolding every policy tree can cost more. |
| Opposed-pair computation | The circuit-described nonempty compatibility class and exact semantic target graph give NP-complete existence of a pair and coNP-complete zero-query identification. Providing a known witness does not remove this obstruction. |
| Succinct deterministic adaptive synthesis | With public registers and response/availability circuits, a finite literal command list and unary horizon, proper minimum-budget decision is PSPACE-complete. This lower bound holds with unit cost, a product latent class and a real one-bit frozen target. |
| Certified approximation | Feasible policies and valid lower bounds maintained on a partial expansion give checkable gaps. For the succinct family, a finite direct fallback with binary tariff gives a gap excluding deterministic polynomial-time multiplicative cost estimation within any fixed polynomial factor of bit length unless P=PSPACE. This does not assert the same impossibility for the explicit factor algorithm. |
| Earlier binary scores | T10's SUBSET SUM reduction persists for compact binary serial scores. Numeric-budget tables are pseudo-polynomial and do not contradict this. |
| Known noisy independent bits | In M02.3, for fixed flip \(\eta\) and stated \(\delta\) range, target costs \(\Theta_\eta(\log(1/\delta))\) and full identity \(\Theta_\eta(d\log(d/\delta))\), both for expected and hard path criteria. The posterior factorization is under the complete adaptive record. |
| Succinct point menu | In T07.K, each completion is described in \(\Theta(n)\) bits plus shared rules and each read returns one bit. With \(N=2^n\) point contexts, exact costs are 1 versus \(N\), and a hard cap \(q\ge1\) gives uniform identity success at most \(\min(1,q/N)\), attained. At fixed noise and error, worst expected target cost is bounded and identity is \(\Theta(N)\). |
| Linked finite transport and monitors | Rational linear optimization on explicit mass arrays supplies exact extrema or valid outer bounds according to source realization. Mode enumeration, full-prefix representations, discovering valid constraints, and independence of certificates have their own costs. Minimum retrospective anchor selection can enumerate exact covers. The prospective solver uses declared public response successors. |
| Finite strategic game | A normal-form LP is exact over enumerated admissible private plans. A polynomial-size explicit-tree sequence-form LP applies to the stated full perfect-recall game. Inheritance of arbitrary succinctness, restricted responders or continuous-family tractability is unproved. A legal truncation after \(H\) probes incurs at most \(B/[c_0(H+1)]\) extra class error at worst expected budget \(B\). |
| Joint safe belief synthesis | Exact dynamic optimization uses complete observable successor beliefs. With finite integral work and acquisition budgets the reachability grid is finite and zero-price cycles need properness. Separate paid and work costs stay separate. |
| Correlated serial flagship | Define \(K_D=1+(D+2)(D+3)/2\). The online solver uses at most \((H+1)(D+1)P K_D^{\max(1,W)}\) records for edge width \(W\), summed meter size \(P\) and integer work deadline \(D\). It suffices for fixed width and controlled numeric inputs, including exponentially many graph paths. The static oracle uses paired graph updates on \((D+2)^2\) capped prefix scores, plus exact outer cover. |

## Structured comparators and external costs

The M02 solver uses supplied separator tables and shared dynamic certificates. Conventional factor elimination and diagram construction already exploit graph structure. T30.CG replaces a potentially much larger subset of \((e,\text{score})\) pairs by exact attained extrema, and compares its own worst bound with that larger structured state representation. An actual solver's reachable subset states can be smaller. A decision diagram, antichain representation or alternative decomposition may resolve further hidden structure. No universal runtime ranking follows.

Legitimate acquisition cost counts calls or declared prices. Computational costs count input representation, preprocessing, search, and proof verification. Physical anchors, useful service, independent trusted measurement and native diagnostic effort have separate charges. Outperforming “buy every query” by itself says nothing about optimal full identity. The largest matched historical X05 case tied at 677, and X12's direct trusted measurement won its recorded cost/coverage comparison.
