## T25.J · Joint monitor identification

### Flow and law

For a completion, set $x_h=P([h])$ and $f_{h,e}=P([\mathrm{child}(e)])$. The children partition $[h]$. For $x_h>0$, the outgoing vector is $f_h=x_h q_h$, so every row inequality or equality scales as specified. For $x_h=0$, every $f_{h,e}=0$ and the homogeneous cuts hold, including when $Q_h$ is empty. The affine evidence already holds on the masses.

Conversely, from a feasible flow take $q_h=f_h/x_h$ at each positive nonterminal. Conservation gives a probability row and its scaled constraints imply $q_h\in Q_h$. The action marginal in this row is the fixed $\pi$. For each action with $\pi(a\mid o(h),s_\pi(h))>0$, draw from its source outcomes with probabilities $q_h(e)/\pi(a\mid o(h),s_\pi(h))$ on its edges. This executes the row under the given policy and the declared support, including its memory and action requirements. The synthetic root uses its supplied sampling row. Starting from unit mass in each tree, induction gives $P([h])=x_h$ and $P([\mathrm{child}(e)])=f_{h,e}$. A null prefix is never called. The law at all terminal histories and the supplied affine evidence therefore agree with the flow. This proves both directions, with terminal masses determining the path law and with no row choice needed at a null prefix.

In each mode the resulting set $P_m$ is a closed rational polytope. All masses belong to $[0,1]$ by root normalization and conservation. The full domain is the finite union of the mode sets, tagged by mode if they use different tree coordinates. A vector of nominated affine statistics is evaluated in each mode by its declared formulas. Its entire joint image is attained, by the same reconstructed law for all coordinates of a point. Violation, miss, and false alarm use the terminal indicators $V$, $V(1-M)$, and $(1-V)M$. ### Defined ratios and thresholds

In a nonempty $P_m$, write any $z$ as $\sum_j\lambda_j v_j$ over the finitely many vertices. The event mass $d$ is nonnegative. If $d(z)>0$, affine evaluation and the premise on $n$ give

$$
\frac{n(z)}{d(z)}
 =\sum_{j:d(v_j)>0}
 \frac{\lambda_j d(v_j)}{d(z)}\,\frac{n(v_j)}{d(v_j)}.
$$

These weights sum to one. Conversely any weights $\beta_j$ on the positive-denominator vertices are attained in this expression by taking $\lambda_j$ proportional to $\beta_j/d(v_j)$, with zero weight at the other vertices. The mode image is thus a closed interval with endpoints at genuine positive-denominator vertices, including when the feasible domain also meets the face $d=0$. A mode with $\max d=0$ contributes only undefined completions. Across feasible modes the defined set is the union of the intervals, and an undefined completion exists exactly when some mode has $\min d=0$. The probability of a miss given a violation has $0\le n\le d$, which guarantees the premise at zero.

For a finite cap $c$, at every positive-denominator point the cap is equivalent to $n-cd\le 0$. At every zero-denominator point $n-cd=0$. If the class has a defined completion, the cap holds over all defined completions exactly when the affine maximum is at most zero in every feasible mode. A positive maximum is achieved by a single feasible law with $d>0$. When every completion has zero denominator, report that the ratio is everywhere undefined. The condition on $n$ is essential to interval attainment in general. For example, with $d=s$ and $n=1$ on the interval $0\le s\le1$, the defined ratios are unbounded above.

For any scalar risk with extrema $L,U$ on a consistent class, the decision at threshold $c$ passes if $U\le c$, fails if $L>c$, and is unresolved if $L\le c<U$. This respects the strict failure convention even when $L=c$. An empty union is inconsistent.

### Exact optimization

Feasibility and affine extrema are ordinary rational linear programs for rational objectives. To optimize a defined ratio with rational affine data, first keep only feasible modes with some $d>0$. Write the mode as $Az\le b,\ Ez=e$, and $d(z)=a^\top z+a_0,\ n(z)=b_n^\top z+b_0$. Use $t=1/d(z)$, $y=tz$, and solve a linear program for $b_n^\top y+b_0t$ on

$$
Ay\le bt,\qquad Ey=et,\qquad a^\top y+a_0t=1,\qquad t\ge0.
$$

If $t=0$, $y$ is a recession direction of the nonempty bounded mode, hence $y=0$, contrary to normalization. Every feasible scaled solution has $t>0$ and recovers $z=y/t$. The vertex argument already establishes attainment for both objectives. Two affine denominator programs distinguish positive-denominator feasibility and possible zero mass. The cap can be tested by a rational affine objective when $c$ is rational. For other exactly comparable caps, use the ratio endpoints.

For a nonempty nominated finite context set and defined risks $r_j(z)$, the upper endpoint of $\max_j r_j(z)$ is the maximum of the separate context maxima over all feasible modes. For the lower endpoint, minimize $\tau\in[0,1]$ within each mode subject to $\tau\ge r_j(z)$ for every context $j$, then take the smallest feasible mode minimum. This is the epigraph of the worst risk on one completion. Affine, fractional and worst-risk programs have polynomial size in the explicit trees, supplied rational coefficients, and the numbers of modes, contexts, and nominated statistics. The number of programs is polynomial as well. Exact optima and counterexamples can be returned as feasible flows and decoded as above. The program formulation gives an implicit image description.

The rational algorithm needs a rational finite encoding of the relevant objective data. The geometric result permits arbitrary real affine statistics. Taken literally for arbitrary such coefficients, the exact rational-LP computation claim needs a qualification. A one-leaf law with $d=1$ and constant bounded score $n=\sqrt{2}/2$ has an irrational endpoint, whereas an exact finite optimum of a rational LP is rational. An unrestricted real coefficient may even lack a finite input description. The event indicators used in M05 yield rational coefficients.

## T26.C · Event fidelity under history-conditional coupling

### Exact paired law and backward recurrence

Fix the original and probed native laws, including their initial and complete-prefix action/outcome rows and their possibly different legal policies. Synchronize the trees by the supplied valid padding. At a paired prefix $w=(h_D,h_P)$, let $R_w$ consist of all outgoing joint probability vectors with the required marginal sums. For example, the sum of entries over companion edges to an original edge $e$ equals $p_D(e\mid h_D)$. Paired support and affine row constraints further restrict this set. In the mass formulation the right-hand side of each projection equation is $x_w p_D(e\mid h_D)$, so the equations are linear. The same rule includes the paired sampling root. Applying the flow-law proof to $R_w$ gives a paired law with the prescribed rows in one direction and the corresponding flow in the other. The projection argument below gives the exact complete native marginals. With only the projection requirements, products of the two local rows give a feasible coupling.

Start with every allowed terminal assigned its given cost. For a nonterminal $w$, form $R_w^\ast$ by requiring zero on every edge to an infeasible child. If this row set is empty, the subtree cannot admit a continuation from unit mass at $w$. If it is nonempty, optimize the row expectation of the feasible child values on this compact row polytope. Use minimization or maximization consistently with the root objective. A single local LP returns an optimum or infeasibility for each nonterminal and each requested objective. Recursively, any law starting from $w$ must assign zero to infeasible children and its conditional child values satisfy the inductive bounds. Conversely a locally optimizing row and attaining continuations at its positive children assemble to an attaining law. Children are disjoint full-prefix subtrees and each imposed restriction here involves just one row. The root therefore gives the optimum and a saved collection of rows gives a witness. A condition spanning several periods or populations belongs in the joint flow program, whose feasible flows can enforce those shared conditions.

### Native continuation and the event scores

At a positive $w$, fix either coordinate and any future native sequence of its edges. Condition successively on each native extension of this sequence. At every step, the paired continuations compatible with the extension partition its mass by the other coordinate's prefix. Each positive part has, by its projection equation, the same next native marginal at that fixed native prefix. Its weighted average is that same row. The resulting probability of the native sequence is the product of its native conditional rows. A zero-probability native extension contributes zero. This proves the full conditional continuation identity, including the exact complete marginals when $w$ is the paired root.

Let $B$ be the union of disjoint paired-prefix cylinders indexed by an antichain $W_B$, and let $d_B=\sum_{w\in W_B}x_w>0$. For any event $A$ of one arm's complete history, the law of total probability gives

$$
P(A\mid B)=
\sum_{w\in W_B:x_w>0}\frac{x_w}{d_B}\,
 P_{\mathrm{native}}(A\mid h_{\mathrm{native}}(w)).
$$

Here each continuation is attached to its known native past, so cylinders at different depths still give laws of the same complete-history type. At a single positive paired prefix the weights select just its two native continuations. For a paired terminal cost $C$, the conditional numerator for $B$ is $\sum_{t\in B} x_t C(t)$ over terminal leaves. It vanishes at $d_B=0$, so the sharp defined conditional range follows from T25.J. Signed risk differences and disagreement have such numerators. Absolute values of signed differences follow by taking the absolute-value image of the signed ranges. The zero-mass possibilities are reported separately.

For the independently scored binary events, the identity $V_D-V_P=1[V_D=1,V_P=0]-1[V_D=0,V_P=1]$ gives $r_D-r_P=b^+-b^-$. Also $P(V_D\ne V_P)=b^++b^-\ge |r_D-r_P|$. The minimum is attained in the feasible class and is zero exactly when an attaining law agrees almost surely on the event. At that minimizer its disagreement bounds the absolute risk difference. The attained maximum is the least uniform upper bound on disagreement in the class.

The same identities hold after conditioning at any positive paired prefix, with the native risks there given by the continuation identity. If a feasible root law gives a prefix positive mass and the restrictions are local, any of its feasible subtree continuations can be substituted there without changing that prefix's mass. The subtree recurrence therefore gives sharp conditional extrema there. On $B$, the two conditional risks use the occupancy-dependent mixture just derived.

### Actual law and independently audited references

Its marginal and positive paired-prefix continuations therefore equal the native ones. For an uncertain actual coordinate, let $h$ have positive actual marginal prefix mass. A useful boundary is an actual deterministic initial prefix paired with an isolated fair bit $I$. The actual subsequently records a binary $L$, with legal actual row $\operatorname{Bernoulli}(p)$ for any $p\in[0,1]$. An audit fixes $P(L=1)=1/2$. ### Pattern masses and decisions

The uncovered global mass is $z_{(1,0,\ldots,0)}$, the global risk is $\sum_{s:g=1}z_s$, and each directed retention difference is $\sum_{s:l_i=1}z_s-\sum_t x_t I_i(t)$. These are simultaneous affine functions of the same feasible masses. The flow-law correspondence gives a realizing joint law for every such vector. Exact computation of the upper or lower global risk optimizes the single total over all $g=1$ patterns. A failed universal bound has a single witnessing law on the complete plant and each supplied reference. If an explicit table lists zero entries for all absent patterns, its output size can exceed the tree size. Summing the represented terminal scores suffices for a scalar objective.

An isolated cap tests $P(I_i=1)$, a containment bound tests $u$, and a directed retention bound tests $P(L_i=1)-P(I_i=1)$. ## Disposition and source obligations
