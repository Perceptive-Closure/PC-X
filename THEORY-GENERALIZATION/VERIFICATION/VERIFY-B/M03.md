## M03.1 Joint trajectory risk

1. In each mode set prohibited trace coordinates to zero. The remaining \(q,s,w,a\) are nonnegative, with all these components at most one by the row and run sums. For a fixed row matrix \(H_{dx}\), multiplying the row constraints by positive \(w_{dx}\) gives \(H_{dx}s_{dx}\le h_{dx}w_{dx}\). Add a variable \(v_{dxy}\in[0,1]\) with \(v_{dxy}\ge a_{dxy}-s_{dxy}\) and \(v_{dxy}\ge s_{dxy}-a_{dxy}\), with \(\sum_y v_{dxy}\le2\delta_{dx}w_{dx}\). The exact absolute differences give witnesses for these lifted equations. Clearing \(a_{dxy}>0\) denominators gives the two stated linear event bounds. At a null denominator the associated masses are zero and the inequalities are homogeneous. No conditional value is constrained there. Conversely normalize every positive row and take \(q_{dxy1}/a_{dxy}\) where defined. This gives the two directions of the mass representation with the original coupling constraints. With bounded auxiliaries and closed constraints the lifted mode is a compact polytope.
2. On any nonempty mode \(C_m\) the continuous function \(R=\max_d r_d\) attains both extrema. For \(L_m\), minimize \(u\) subject to \(u\ge r_d\) for all \(d\), adding \(0\le u\le1\) without changing the optimum. For \(U_m\), interchange the two finite maxima over \(z\) and \(d\) to solve one linear optimization per run. If \(z_L,z_U\) reach the endpoints, their joining segment stays in \(C_m\). The image of that segment by continuity includes all intermediate values. Thus that mode's risk image is \([L_m,U_m]\), and the union over inhabited modes is exact. The threshold comparisons follow from attained extrema. If both homogeneous tests fail, an inhabited mode has a minimizer with risk \(\le\tau\), and some inhabited mode has a maximizer with risk \(>\tau\). If all modes are infeasible report inconsistency before point classification. Exact physical endpoint witnesses use the stated realization premise. With only outer inclusion, the LP can still prove uniform conclusions for actual deployments, while an outer feasible array or mixed classification gives no physical disagreement witness on its own.
3. Hoeffding gives \(2\exp(-2n_i\rho_i^2)=\alpha/K\) as the two-tail bound for the independent observations with common mean in the faithful fixed batch of cell \(i\). A union bound gives the common coverage event without cross-cell independence. If the anchored discrepancy from reference to deployment is at most \(\eta\), the triangle inequality gives \(|p_D-\widehat p_{\rm ref}|\le\eta+\rho_i\) in the matched positive cell on that event. Intersect that interval with \([0,1]\). Every jointly covered, operationally justified restriction selected from the registration keeps the actual array and mode on the same event. A wrong homogeneous certificate entails failure of that event, so its unconditional probability is at most \(\alpha\). This remains true after outward rational rounding. Conditional error given issuance can differ, and issuance can fail to occur. Exact computational LP claims use a supplied effective ordered coefficient representation, including rational data. [Hoeffding's original inequality](https://www.cs.rpi.edu/academics/courses/spring06/random/hoefding.pdf)

The clearing in part 1 uses a fixed linear map \(H\). If the row condition is meant to allow arbitrary functions, choose one run and one context with binary \(Y\), set TV radius zero and \(V=Y\), and constrain the reference success probability \(p\) by \(p(1-p)\le0\). The mode realizes exactly the two risk values \(0,1\). It is neither a polytope in the specified mass coordinates nor an interval risk image. With \(H\) a matrix, the proposed construction and image apply as stated.

The full-trace policy-flow condition can be enforced by summing over continuations of prefixes. For each applicable refined prefix \(u\) with controller information \(h(u)\), use
\[
q(u\cdot a)=\pi(a\mid h(u))q(u)
\]
when the declared genuine policy kernel applies to that prefix. Include retained controller information and actual randomness constraints in the refinement that justifies these kernels. This is linear in complete-extension masses. For a control, equiprobable hidden states \(0,1\) with the same observation precede an independent fair-coin action. Trace masses concentrated equally on \((0,a_0),(1,a_1)\) have the correct aggregate action frequencies. At hidden prefix \(0\) they assign \(q(0,a_0)=1/2\) instead of the required \(1/4\), so they do not realize the fixed policy. Prefix equations can enforce policy flow. Other restrictions on environment kernels, context couplings, shared memory and trusted scoring require their own compatibility proofs.

Two further risk controls distinguish the target from marginal outcome fitting. For two runs with one outcome letter, impose \(r_1+r_2=1\). Their separate minima are both zero but the minimum of the maximum is \(1/2\), attained at \(r_1=r_2=1/2\). The exact interval is \([1/2,1]\), mixed at threshold \(1/2\). For one run and one observable outcome letter, set matching reference/deployment outcome rows and TV radius zero. Allow both physical event bits at that letter and leave event rates uncalibrated. Risk can still take both \(0\) and \(1\) under the same outcome law, illustrating the need for a trusted event restriction at that cell.

## M03.2 Minimum sufficient anchor facts

1. The full vector of realized facts is jointly inhabited, so every selected subset has a nonemptiness witness. For a subset \(J\), an opposing completion survives precisely when it violates none of the facts indexed by \(J\). Equivalently \(D(z)\cap J=\varnothing\). Thus target certification is exactly the asserted hitting condition. Separate line items for acquisition and verification add to each distinct read's cost and are independent of deployment execution. Given a candidate \(J\), intersect its selected facts in each mode and test opposite-label existence. For an opposing PASS, solve feasibility with every \(r_d\le\tau\). For an opposing FAIL, maximize each \(r_d\) on each feasible mode and require at least one optimum strictly above \(\tau\). Equality to \(\tau\) supplies no FAIL witness. A surviving completion supplies a pattern disjoint from \(J\). If \(J\) hits all collected patterns this pattern is new. If no opponent exists, the minimum-cost solution to the relaxed hitting problem is genuinely feasible and has attained its full optimum because no full optimum can cost less than the relaxed one. An empty pattern forbids any certificate and leads to optimum infinity. There are at most \(2^{m_a}\) patterns and exact primal witnesses or dual absence checks in the LP representation.
2. Store a partial response tuple and retain exactly all mode, array and full-tuple possibilities extending it. This is a finite collection of intersected polyhedra indexed by mode and full tuple, with feasibility and class checked by the same strict-threshold rule. At a nonempty homogeneous state, stopping costs zero. At a mixed state any proper strategy must choose an unread read. Its feasible outcomes are exactly those occurring in some retained possibility, and the full tuple is immutable, so following a child corresponds to adding that reply to the same hidden tuple. By induction on the number of unread queries, a choice \(i\) has minimax cost \(c_i+\max_a W(h\cup\{i=a\})\). Minimum over choices gives the value and an attaining tree when finite. A mixed terminal has value infinity. The root is handled as inconsistent if the base class is empty. Overlap of projected compatibility sets causes no issue because the state retains all admissible tuples and the audit must classify each of them.
3. A direct read at the root or the optimal semantic tree gives an upper bound \(\min(d_0,W)\). A policy with worst-path cost less than \(d_0\) cannot use the direct read on any feasible path, since it pays \(d_0\) there and all other costs are nonnegative. Such a policy is semantic-only and costs at least \(W\). Every combined policy therefore costs at least \(\min(d_0,W)\). This proves the strict advantage criterion for the specified unchanged, constant-cost exact read.
