## M01.1 Finite source equations and certificates

Represent a permission value by its membership vector on the registry and an equivalence relation by its pair table. Enumerate only the tables in the declared types. For each slot tuple \(\theta\), evaluate the total entry, compatibility and observation circuits. At \(s\) the action \(a\) lies in \(Q(s)\) exactly when its ordinary guard holds and its permission bit is set. Collect its successor table by disjoining alternative guards of positive weight that give the same whole postcheckpoint. The \(Y(s,a,u)\) circuit is single-valued even if several alternatives reach \(u\). Action identities, costs and controller-visible fields remain those of the source.

Unfrozen physical reachability is the least fixed point seeded at the entry under the admitted support table. Retain \(n\) rounds of reachability equations for \(n\) checkpoints. For each state the fiber bit of \(x\) is true exactly when some \(h'\) has \(p(h,h')\) and \(x\sim_\theta h'\). Validity checks nonempty reachable fibers and nonempty successors at every reachable admitted occurrence. Closure at a valid reachable state is pairwise equality of \(A_\Pi\) over its fiber. Each mask bit tests whether some supported successor has an unequal corresponding source field. Freeze and keep processing then use these masks and the unaltered successor table.

Propagate nonempty beliefs by common legal actions and full children indexed by \((Y,\omega_{\rm next})\). A tree has worst branch cost at most \(b\) when its root stops legally or has one common legal kept action of price \(c\le b\) with every feasible child using budget \(b-c\). The depth recurrence for exact values uses zero at a closable belief, the minimum over common actions of price plus maximum child value at an open belief, and infinity for inability to close. Its depth-zero value is infinity at an open belief. Using each of the eight keep masks gives its signature coordinate.

If a belief occurs twice along a branch of a finite proper tree, substitute the later subtree at the earlier occurrence. Legality and the full child support update only depend on the belief, fixed keep mask and action. Every replacement path is legal and remains observation-measurable. The later subtree's worst cost is at most the previous subtree worst cost because all costs on the intervening path were nonnegative. The number of tree nodes decreases. Repeat until each branch has distinct nonempty beliefs. There are at most \(2^n-1\) such beliefs, so the stated depth suffices. This provides an attained optimum whenever there is a finite proper policy, including zero-cost cycles. For rational prices multiply by a common finite denominator and use a separate infinity bit.

Trace atoms are finite path existence tests in the source-generated table with the declared record, locator and end conditions. If the atom describes controller histories, replay the prescribed common-action and belief checks as well. Instrument outputs are the specified total source-grounded values. They enter the controller record only if declared in the observation interface. All calculations have finite expansions with acyclic local Boolean equations for each slot input. This gives a unique evaluation by induction on equations. Enforcing validity and \(\Omega\) produces exactly the compatible interpretations under the source premise. A fixed total extension can supply any otherwise inapplicable fields for invalid slot tuples, which the validity check excludes.

1. A concrete slot tuple with replay of the equations witnesses consistency and membership of a joint target value, including within a readback cell. Finite exhaustion or a checked Boolean refutation witnesses exclusion. An exact singleton certificate includes both membership and exclusion of every other value. Nonempty finite ordered images have attained extrema.
2. An opposite-target witness gives both slot assignments, their exact targets and all required readback equalities. Exhaust the corresponding pair predicate to certify that the given full readback vector separates every opposite pair. If it fails, either world returns the same response to any chosen catalog read. Couple the auditor's private coins and induct on full histories. Adaptive selection then has the same report law in both worlds, whereas certainty requires different labels. If every opposite pair is separated, the completed answer vector determines the target on its compatible cells.
3. For integer costs unroll the Boolean recurrence over depth, budget indices \(0,\ldots,b\), and nonempty beliefs. A common action's keep restriction is \(\bigwedge_{s\in B} k_{s,a}\), a term only exists for fully available actions, the child test is an AND and the alternative-action test an OR. These give a monotone circuit. Each kept-set witness uses only a subset of those occurrences and its exact reachable support still suffices. Each proper policy whose actual support is contained in a kept set certifies that set. The inclusion-minimal sets coincide. Substituting \(k_{s,a}=1\{T_s(a)\cap F=\varnothing\}\) gives whole-atom freeze.
4. Finite enumeration and local replay give certificate systems for the declared encoding. A timeout or satisfiable relaxation cannot certify the exact predicate.

An exact mask control uses two opposite-target worlds, an open representative for both, and a closed representative for one. At the sole entry one unit-cost atom has two supported alternatives with weights \(1\) and \(1/7\). Both successors close and change admission. Only the second also changes the equality table by merging two unused representatives. The mask is \(\{E,R\}\), baseline cost \(1\), and R-freeze cost infinity. Setting the second weight to zero gives mask \(\{E\}\) and R-freeze cost \(1\).

## M01.2 Directed observable cover

For a fixed freeze, keep a virtual source history along each receiver history. At a source stop use the same label by stopping-menu inclusion. For each source action the cover supplies one common receiver atom. The receiver union mask is contained in the source union mask, so the chosen action survives the freeze. On visible receiver label \(\ell'\), advance the source virtual branch by \(\sigma(\ell')\). The two child beliefs are related. Kept actions retain their full children from the unfrozen graph. Induction on the finite source tree proves properness, depth at most the source depth and termwise path costs no larger than the virtual source path. The receiver can compute its virtual history from the successive observable labels using the prechosen witnesses.

Transport for every proper tree gives all eight inequalities. Covers each way give equality, including at infinity, preserving the definition and value of the R penalty and baseline unclosability. Under accepted T03 symmetry, lift those reachable belief pairs whose members are covered in both directions by the physical relation. Related checkpoints have the same observation. The common action and outcome renamings act on the whole belief. Pairwise matching occurrence masks give equal union masks, and forth and back give coverage of each matched child belief. This gives the stopping condition directly for plain closure. For common reports it gives the condition if the declared menus respect the preserved report classes. If independent reporting rules are allowed, take identical one-state closed plants with a single matching physical class and no actions. A rule permitting the common report in the source and a rule requiring an additional unfulfilled reporting prerequisite in the receiver preserve the physical T03 pairing, but their stopping menus fail inclusion. The T03 implication for this reading needs report-menu preservation explicitly.

For the converse, use a unit-price E-only closer at the first open entry and two distinct unit-price E-only closers at the second, deterministically to an isolated closed checkpoint in each plant. Equal and constant observations and outcomes suffice. Each action has a receiver mate in each direction. Entry menu cardinalities differ, precluding T03's menu bijection.

Even equal signatures can admit no cover in either direction. Retain a single unit-cost E-only closer in both plants. Add a free action to an open dead end in each, with mask \(\{E\}\) in the first and \(\{R\}\) in the second. For an extensional realization choose \(h_o,h_{o'}\) each compatible with both opposite-target worlds, \(h_c\) compatible with one, and two unused representatives with no compatible world. Use \(h_o\) and discrete equality at entry, and a constant permission table everywhere. Each closer changes admission to \(h_c\) only. The free E atom changes admission to \(h_{o'}\) only. The free R atom leaves admission at \(h_o\) and merges the two unused representatives. Location guards disable actions at all endpoints. Both signatures are \(1\) when \(E\notin F\) and infinity otherwise. A matching atom for either free move would have to be free, and the two masks are incomparable.

For explicit graphs, start with all pairs satisfying the stopping-menu test. Remove any pair for which some source action has no receiver action satisfying cost and mask bounds and a remaining child pair for each receiver label. A source label for each receiver label may be chosen independently. A true cover survives every deletion, and the stabilized relation is itself a cover. Both the number of possible deletions and the size of a local check are polynomial in the expanded graphs.

For exact cost transport, equality of move costs gives equality along each matched path. Surjectivity lets each source path be realized in at least one receiver path by inductively choosing preimages of its labels. Hence the maximum path cost is equal. The strengthened condition in each direction gives equality of attainable proper worst-path cost sets.

## M01.3 Physical realization and unbounded sources

A concrete deterministic source has one authorized send atom and a setting field selecting either certified loopback or installed deployment. In evaluation the field is pinned to loopback. In deployment it selects the installed receiver. Both runs send the same payload and emit the same public sent acknowledgement. The loopback inbox always receives the payload. The installed receiver's payload-enable record \(b\) gates actual receipt in the deployment inbox by the terminal checkpoint. A raw state vector containing the setting, phase and inbox flag realizes these deterministic postconditions. Use a fixed permission and equality table and a single authorization world to make all reachable fibers nonempty. The failure predicate in both assignments is absence of the payload in the addressed physical inbox at the terminal deadline. The program and full evaluation trace, including loopback receipt if recorded, are identical at \(b=0,1\), while deployment failure equals \(1-b\). A separately authorized pure measurement of the enrolled installed enable record makes both readback cells nonempty singletons of the target. The evaluation profile never accesses that record.

For unbounded deterministic small-step sources, place a Turing machine's tape, head and control in raw state initialized with a given input. Fix two worlds with distinct targets and fixed discrete equality. Admission \(h_o\) is compatible with both and remains open, and \(h_c\) is compatible with only one. Every running checkpoint has the single authorized tick with a deterministic successor executing one machine step. Keep \(h_o\) until the simulated machine halts, when admission becomes \(h_c\) and tick is disabled. An initially halting configuration can begin closed. Constant visible outcomes, fixed permission, unit cost and no slots suffice. The unique interpretation has nonempty reachable fibers. A proper finite closer exists if and only if the machine halts. A terminating exact existence compiler over all these sources would decide halting. [Turing's original undecidability argument](https://theory.stanford.edu/~trevisan/cs172-07/turing36.pdf)
