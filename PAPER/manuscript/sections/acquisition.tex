\section{Buying enough information}\label{sec:acq}
A team might want the cheapest record supporting \emph{this} installation, a fixed list of checks that works everywhere, or a procedure that chooses its next check from the replies. Their prices can differ. For a realized evidence vector, the first problem needs to exclude only completions with a different answer from the one certified. The second must separate all contrary pairs. Minimum total price under either condition is a weighted hitting-set problem: select a least expensive set intersecting the corresponding family of disagreements (Theorem~\ref{thm:t06}). Replaying an inexpensive realized certificate gives no prospective worst-case price unless the same plan works on every reply.

For the third problem let \(S\) be a current nonempty cell of compatible completions, including any observed access state, and \(S_{j,z}\) its successor after read \(j\) returns \(z\). In the finite once-only positive-information model let \(c_j\) be its price and \(v(S)\) the minimum additional worst-case price. A homogeneous cell costs zero. At a mixed cell,
\[
 v(S)=\min_{\text{available }j}
       \left[c_j+\max_{z:S_{j,z}\ne\varnothing}v(S_{j,z})\right].
\]
The remaining menu is part of the state where needed. A dead end has value \(+\infty\). The first move of any policy pays the displayed price and faces each supported answer. Conversely, joining optimal child policies after their observed answers attains the displayed minimum. Induction on the remaining menu proves the recursion. Dynamic authority, stochastic reports and support-robust work require the appropriate progress resource and successor record (Theorems~\ref{thm:t08} and~\ref{ext:m021}).

\paragraph{A two-read audit in the release example.}
Suppose every admitted path goes through either a primary finalizer or a fallback. A signed read of each operative guard costs one unit. The target is that both guards enforce authorization. Other implementation fields remain unknown. A fixed list that decides the question everywhere needs both reads. An auditor who chooses the primary read first can sometimes stop sooner, as Table~\ref{tab:audit} shows. The cheaper negative receipt is a \emph{realized} certificate. Promising one unit before seeing any report would underprice the task. A direct instrument that checked both paths at once would define a different menu.

\begin{theorem}[A target cheaper than installation identity, T07.K]\label{body:key}
For each \(n\ge1\) consider the governed two-job service with \(2^n\) contexts of Theorem~\ref{ext:t07k}. One unit-price gateway query determines whether both jobs can be completed in every context within work budget three under the representation freeze. Deterministic exact identification of the entire installation has minimum worst-case price \(2^n\) on the same unit-price interface consisting of the gateway read and single-context key tests. Neither audit receives free trial executions. If \(A_\Psi\) and \(A_C\) denote the least deterministic worst prices for exact target and identity, respectively, then
\[
 A_\Psi=1,\qquad A_C=2^n .
\]
\end{theorem}
\begin{proof}
An installation stores a hidden gateway bit and an exceptional \(n\)-bit key. During service the representation is frozen. The one-unit fast gateway action survives the freeze only at a fresh gateway, and the one-unit fast context route survives exactly off the exceptional key. The separate slow actions always survive: three units for the gateway, two for the context job. The gateway read and point tests are separately authorized pure audit commands available before service in every installation. With a fresh gateway the common plan spends at most three even without the key. With a stale gateway even the cheapest second action exceeds the budget. Thus one gateway read suffices and opposite gateway values show that no reads can certify both. To determine identity, each negative point query rules out only its own key. In the worst case \(2^n-1\) such queries and the separate gateway read are necessary and sufficient. Changing the key changes a real available route in the exceptional context.
\end{proof}
The exponent measures the succinct key length \(n\). A failed point query rules out a single key, the familiar lower bound for unstructured search. The role of the service is to make the key matter to an actual work route while proving it unnecessary for this deadline. In a separate noise model, each answer is independently flipped with the same known probability strictly between zero and one half, conditional on the question and past. For fixed noise and a fixed uniform wrong-or-abstain allowance below one half and above zero, repeated reads give a constant worst \emph{expected} price for the target and order \(2^n\) for identity. An installed-key read or a jointly executable, faithful identifying menu of polynomial total price removes the stated exponential lower bound for that richer interface. In the release example, full compiler identity can be economically irrelevant, but its actual cost saving must be shown for the available reads.

\paragraph{Finding a least-cost audit (T14).}\label{body:oracle}
An exact optimizer can work with a short list of known disagreements even when there are many possible systems. Start with no pairs. Find a minimum-price list of reads meeting every disagreement collected so far. Give it to a \emph{complete separation oracle}: a procedure that either produces a verified, target-opposed pair agreeing on every selected read or certifies that no such pair exists in the full declared model. Add a new pair's disagreement set and repeat.

Let \(m\) be the number of eligible reads. An empty disagreement proves inaccessibility. Otherwise a returned set is nonempty and new, so there can be at most \(2^m-1\) additions. At a certified stop the chosen audit works for every possible pair; its price was already a lower bound on the optimum because it solved a relaxation exactly. This proves optimality. A verifier may find a pair by a symbolic search without listing every completion. Its completeness, its computational cost and the cost of solving each weighted selection problem are substantive assumptions. A timeout supplies neither a certificate nor an impossibility result (Theorems~\ref{thm:t13}--\ref{thm:t14}).
