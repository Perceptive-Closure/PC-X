# EXP-X04 protocol v1

The parent-approved work plan, charter pp. 8–13 and 34–37, and the JSON configuration fix this finite deterministic study before any X04 outcome is evaluated. The study tests T05–T10 in explicitly enumerable domains. It measures observed acquisition costs in these constructed domains. The address controls and routed workflows establish no tractability or generalization claim beyond the tested regimes.

## Semantics and estimands

A completion row contains answers to every authorized deterministic query and its target. Start with every completion admitted by the frozen domain. A query of positive integer cost restricts the belief to rows consistent with its answer. Only a nonempty target-homogeneous belief permits certification. A mixed equivalence class for all authorized answers gives an exact inaccessibility witness. An empty domain is inconsistent. Queries and tie ordering are fixed in the configuration and generators. Authorization of the queries is an assumption of each synthetic source contract.

The primary measurement is minimax total cost over positive-support paths. Verify the hierarchy maximum realized certificate cost ≤ adaptive minimax ≤ minimum uniform static cost, with unattainable costs represented by null. Report exact prior-weighted costs for terminating policies separately from worst-case costs. Priors assign mass proportional to positive row weights. Weights are uniform for explicit address, named generic controls and X03 fixtures. Routed weights are equal within each route and uniform across routes except the prespecified skew. Seeded rows draw weights from the frozen integer range. No prior enters the exact minimax objective.

## Workload and controls

- Eight generic controls cover inconsistent evidence, a constant target, no-query and full-answer inaccessibility, the local/adaptive gap on three-input majority, categorical and weighted queries, full-query parity and uniform cost scaling.
- Address width r uses r binary address facts and one independently variable data fact for each of the 2^r addresses. The target is selected data. Enumerate every completion for widths 1 and 2. Derive bounds for the larger frozen widths without constructing those domains. Static identification requires all r + 2^r individual facts because, for each omitted fact, a pair differing only on it can disagree in target. If t address facts are observed at a successful leaf, all 2^(r−t) candidate data facts must have been read. This costs at least t + 2^(r−t) ≥ r + 1. Reading the address then the selected fact achieves that bound.
- Each routed authorization contract specifies a live source dispatch and an independent configuration at each allowed endpoint. The entry's dispatch is a touch-free logical edge of execution cost 1. At an evidence endpoint, the fast attestation either admits verified history (E) or refines certificate equivalence (R). At a representation endpoint, it admits verified history with or without a simultaneous remap (ER or E). At an authority endpoint, its E-only fast attestation is either initially licensed or can follow a separately authorized grant (A). Fast cost 1, fallback E-only cost 4 and grant cost 4 are shared. Worlds compatible with current or aliased history disagree on approval, while verified history or refined equivalence closes the target. All endpoints are legitimate independent intake checkpoints in the same contract. Configurations affect their own R-frozen costs even when the root is dispatched elsewhere. The root target is the independently evaluated R-frozen closure cost, and the audit sees the dispatch-table endpoint and each permitted endpoint's factual configuration. Each such configuration is an admission, remap or license fact. None exposes the root outcome. Apply freezes by extensional differences in history, equivalence and available authorized actions. Check all eight freeze values against a separate enumeration of feasible direct and grant paths. Observe both weighted variants and two interface-removal ablations.
- Use the five actual structured X03 fixtures at the pinned commit. Cross-check the static and per-completion certificate statuses and costs against its published scope rows, and its independently derived fixture tables.
- Generate 64 seeded domains in four equal strata. For each case draw query and completion counts from the frozen ranges, then positive query costs. Draw independent binary or categorical answers in their corresponding strata. In the correlated stratum project three latent bits through a fixed repeating basis of raw bits, XOR and AND. In aliased cases force the last row to match the first row on every authorized answer while giving it a different target. Draw row weights and targets separately on the same fixed seeded generator. Use a balanced positive seed schedule based on the listed stratum order and within-stratum index. All cases enter the ledger under fixed names.

## Comparators and independent checks

Measure a minimum uniform static policy, full acquisition in frozen order, weighted greedy partition reduction per acquisition cost, prior-weighted cross-target edge cutting per cost, and 16 seeded random adaptive policies that select uniformly from informative queries at each visited decision. Greedy partition reduction minimizes the expected surviving row count per information-cost tradeoff. Cross-target edge cutting weights each initial cross-target pair by the product of its two prior weights and reduces expected surviving edge mass. This is the deterministic disjoint-target version of the cited decision-region idea. Ties use frozen order. Every policy can abstain on a mixed cell only when its full authorized answer vectors can no longer distinguish its targets.

Build the candidate minimax policy with a memoized belief-value recursion. Independently check its budget threshold by search over answer histories and remaining acquisition cost. Verify static and realized minimum costs by independent subset enumeration. Independently replay each emitted policy from every possible completion, validating available queries, complete reachable answer branches, justified stopping and accumulated cost. Deliberately corrupt leaves, answer branches, query names and completion-ID dispatch. Report counts and per-completion paths, status, cost, baseline optimum gaps, coverage and exact weighted means. Measure each exact solver call's elapsed time and traced Python peak bytes and retain these as host observations. Compare raw deterministic evidence to its committed digest independently of hardware timings.

A strict advantage is a finite routed instance with adaptive cost below static cost. Denominators include every routed condition and the finite feasible subset. Treat the generic address calculations as a structural control. Unsupported wide domains receive algebraic bounds only, and the timing record covers executed explicit cases.
