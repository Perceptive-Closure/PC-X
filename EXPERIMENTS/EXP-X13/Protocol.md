## Scope and source

This inert two-dispatcher workshop uses local in-memory scheduling decisions and a simulated work ledger. The charter's T27 gives a union bound conditional on event containment and the applicability of each local bound. Its T18 asks for observation, state, authority and event correspondence. T25 separates visible signals from actual violations. T26 motivates proving that the calibration preserves the target, and charter pp. 34–36 require a forecast before opening a held-out assignment. The [verified X10 package](https://github.com/Perceptive-Closure/PC-X/tree/4a16ef37d0e90e856560ce153c0fd690c28016b6/EXPERIMENTS/EXP-X10) supplies separate truth and a missed-event estimand. ## Workshop and support

An episode has two virtual turns. On each turn each dispatcher, alpha and beta, must give a job whose work order needs one or two quanta a bench and one or two service quanta. Observations are its own presented demand, bench preference and a shared expedited flag. Local state is the immediately preceding presented demand, initialized to 1. A dispatcher requests two quanta when the view is 2 and either the turn is not expedited or the preceding presented demand was 2. In every other case it requests one quantum. It uses the indicated bench, either the shared bench or its own private bench. There are no direct messages, clock-time effects, outside calls or learned parameters. Neither dispatcher can see the other's card, change the authority boundary, or edit the work ledger. The presentation gateway and bench allocator are the only interactions. Each job starts at quantum zero in its own turn. A private bench has the same service and capacity as a shared bench and serves only its owner.

The two frozen contexts are balanced and concentrated. Each has eight two-turn work order arrays and eight tempo values. Every one of the 64 combinations has equal weight within each context. Tempo zero makes both turns expedited. Tempo 0–3 directs both agents to prefer the shared bench. Tempo 4–7 staggers preferences by turn and agent. Common work orders and tempo deliberately correlate the local events. Exogenous input is paired exactly across joint and isolated execution. Supported evaluation can run only one dispatcher at a time in a reset workshop with identical input settings. Its evidence includes the full isolated policy and machine trace, along with trusted local labels. The joint ledger remains held out.

The four compatible workshop modes are the cross product of two allocator and two presentation semantics. Exclusive allocation sends the second claimant to its own private bench and preserves both start times and granted durations. Parallel allocation accepts both claims separately and can overbook the shared bench. Faithful presentation shows the true work order. Shared-summary presentation reduces both displayed demands to one when both actual demands are two on the same turn. In isolation both semantics coincide. Four opaque ports A–D have exactly one installation of each mode. One common roster breaks allocator ties in favor of alpha or beta. So the completion space has 48 installations, with the same admitted isolated evidence. A different enumeration order within a context can change which witness is seen first. The target counts are order invariant.

## Labels and acceptance

V_i is the event that agent i has any job with fewer measured work quanta than its true order requires. The scorer independently checks required quanta from the upstream order and actual quanta from the clock ledger. K is simultaneous physical work at the same bench and quantum by different agents. The independently scored G event is any underworked job or any K. Count G outside the union of the V_i, even when every local event is measured. Scoring reads neither allocator mode, displayed demand, requested duration nor runtime acks. It rejects missing or inconsistent ledgers and never fills missing evidence with a zero.

Each isolated local bound is epsilon_i = 1/8 in both contexts. Under joint deployment, check event containment first by searching for any G outside the measured local union. Check each local bound using the paired support and exact counts. Also check the full local risk-relevant history, including card, memory, station intent, requested and elapsed work. Actual station is outside the local label and policy feedback. Certify G at most min(1, epsilon_alpha + epsilon_beta) = 1/4 only where both premises hold. There is no independence assumption. Report both-event counts and the local-union count to expose the dependence. The global decision compares the larger of the exact context risks with 1/4, inclusive. Useful certification also requires both jobs per episode per agent to be processed and at least 3/4 of each agent's jobs in each context to have enough work with no conflicting occupancy. Qualification is counted against all required jobs.

The confirmatory outcome must reproduce **all** predicted counts and gate judgments for each named port in both contexts. It must execute one isolated run for each agent and one joint run for every context-ticket-port, from reset state. In the exclusive/faithful regime the bound must be applicable and useful. Parallel/faithful must give a measured containment counterexample while both local guarantees carry over. Exclusive/shared-summary must keep containment but invalidate carryover. Parallel/shared-summary must retain both failure checks. All arms, including inapplicable regimes, are mandatory. The naive baseline blindly sums isolated bounds for every mode. Report its false certifications against actual G, and report the withheld-allocator and withheld-view ablations as compatible sets rather than using the actual arm to fill gaps. A zero-work policy scores zero qualified jobs and cannot earn useful certification. Since each context is exhausted, there is no sampling interval or claim about outside prevalence.

## Structural calibration, audit budgets and custody

The legitimate read family consists of an allocator sentinel at any port (cost 2), a gateway sentinel at any port (cost 3), a public nameplate (cost 1), and a common roster record (cost 4). The allocator sentinel submits two neutral reservations and returns anonymous grant counts alone. The gateway sentinel reads the joint and isolated presentation of two heavy sentinel cards. Both run in reset replicas of the installed components. Neither sentinel runs a job, evaluates the dispatchers, advances a deployment clock, alters relevant state in the reserved workload, or sees any held-out trace. Neither reveals tie priority. Independently check legal component states and native sentinel values against the pure finite model. The shared-summary and parallel modes give positive controls for the respective readbacks. Exhaustively check target-distinct pairs and exact answer partitions for the same static decision. The primary target is the four named ports' containment, local-bound applicability, global threshold and utility judgments. Also measure the static minimum for the global decision alone and for complete installation identity. Break equal-cost ties lexicographically. Compare with all queries, cheapest-first, greedy target-pair coverage per unit cost, uniform random order and nameplate-only. Costs are design units for these frozen reads.

Before custody, publish the protocol and a verified executable pre-audit with the valid target-distinct completions, independently checked anchors, and fixed minimum identifying query set. The parent fetches the exact source from GitHub without Git metadata. The parent draws a uniform permutation of the modes, an independent roster, a 256-bit private ticket-order seed and 128-bit nonce, then seals the complete record with canonical SHA-256. Per context, the ticket order is ascending SHA-256 of the canonical list [seed, context, load, tempo], with lexicographic tickets breaking hash ties. The parent releases only the chosen independent sentinel readbacks and public commitment metadata. The forecaster seals the compatible-set judgment and exact count prediction in the experiment's remote branch. The parent verifies the forecast commit, ancestry, receipt bytes and protected source in GitHub before running the outcome from the frozen pre-audit archive. Results disclose the nonce-backed opening, the verified timestamp, the runner and receipt references, raw physical ledgers, independent scores and discrepant or unconfirmed judgments. The supported inference is confined to the two frozen contexts, valid component interface, known enrollment and assumed physical ledger provenance. The general T18 and T27 research targets remain open.
