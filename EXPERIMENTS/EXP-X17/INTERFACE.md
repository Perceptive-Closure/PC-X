# Native and computational agreement contract

## Source, decisions and independence

One immutable rational installed tuple \((\theta,\beta,m,k,B,N)\) governs an attempt. Its synthetic source does actual intake/reconciliation, emits a verified route receipt, makes the chosen route literal physically callable, then one low/high/skip command and one binary declaration. A counted positive drives one guarded finish after the carried responder commits to its proposal. All side effects are bounded to disposable synthetic storage. Interventions in controls use only isolated synthetic records. The ordinary target protocol and nominal governed protocol have separate outputs and true diagnostic scopes.

A source object and raw private ledger never enter the controller input. Pass only detached plain public delivered data (prelude, authenticated route receipt, declared probe response, no truth) and private controller randomness independent of native draw streams, with a pure registered controller. Native inventory names, public tokens, errors, receipt signatures, guard records and all other considered delivered fields must maintain the matched pre-probe law. Prefer deterministic test receipts independent of world secrets and typed public fields. Record exact implementation timing and phase events in the out-of-band ledger. A shared runtime/host cannot attest safe execution of arbitrary controller code. Never pass ambient credentials or real data to the native artifacts.

## Interfaces and role adaptation

Keep small explicit importable APIs for world install, custody/source check, public intake/prelude, route literal probe, declaration/finalization and private trace/artifact export. Publish exact method names and the artifact schema before independent adapter completion. Controller policy should have separate pure functions for probe choice and binary declaration with caller label, delivered public fields and a private RNG; accept both routes, normalize only actual emitted fields. Nominal shadows use the same actual installation and seed under the nominal finalizer. Expose exact matched closed-form forecast by world and arm as machine-readable fractions. Parent runner and independent runner must compute true event and utility from the durable inventory and routed artifacts. Seed selection and audit logs stay separate from the public controller record.

Use durable synthetic artifact batches with explicit transaction/checkpoint or equivalent durable append. Record enough actual data to reconstruct route/receipt, paid charge, advance/late state, actual authority, proposal/event order, accepted draw receipts, original and durable artifact digests, final output bytes or deterministic replay inputs. Publishing a deterministic seed/worklist manifest, content hashes, indexed compact metrics/raw evidence and representative full artifacts is acceptable where another reader can recreate and verify all outcomes. Assign role-local scratch for bulky live files. Preserve and document any invalid outputs.

## Shared working design before freeze

Five native policies use lowercase IDs \`pcx\`, \`high_skip\`, \`low_only\`, \`always_high\`, \`no_paid\`. The low-only illustrative policy takes low and declares positive on 0; the best attainable uniform low-menu error is independently checked. The no-paid native sentinel makes a fair binary report. The structural tests use explicit and counted optimizers, and wider-menu, privileged and setup costs are reported separately. All actual native samples are conditional on good guard auth for the primary. The primary confidence plan uses eight roster rows and 4,096 samples per world/arm per role, fixed before opening; source and control calculations may evaluate the domain deterministically. Only non-roster development calls before release by parent. The design will record a common safe seed schema, no user data.
