# EXP-X17

Prospective validation of the accepted U.G3 synthetic guarded inventory and routing service. Eight installations were selected with a future signed Quicknet round after both prediction implementations and all registered inputs had been frozen. The primary and independent native runs completed 327,680 valid main attempts across five policy arms. The exact matched optimum is 7/12 expected probe charge, compared with 2/3 for high-plus-skip. In both runs the registered conditional physical-risk cap of 3/8 was supported in all eight PC-X worlds. Some tighter equivalence, decision-error and coverage endpoints remain inconclusive.
