# Cost model

| Object | Units and measurement |
| --- | --- |
| Base source catalog | Ordinary specification 1/8, guard authentication 1/4, full inspection 1. These are synthetic charged units recorded on the actual receipt. Minimum sufficient realized good check is compared within the sealed actual catalog. |
| Repeated paid probes | Route-specific low 3/8, high 1, skip 0. Price is an exact integer number of eighths from the native ledger. Expected, worst expected, observed mean, and maximum supported are recorded separately. |
| Trusted-direct extension | Authorized C17 read 1/2. Its information, law and allowed plan differ. Setup, work and intended risk goals stay matched. |
| Operational effort | Record actual reconciliation and finalization counts, phase work and artifact storage. Useful work and true outcomes use separate fields and carry genuine outputs even on nonissuance. |
| Construction and optimization | Record wall CPU/timing boundaries, counted versus explicit state sizes, measurements and coefficient bit sizes, where run. Python memory is a measured approximation of the chosen instrument, with runtime and source compilation separately disclosed. |
| Optional calibration and extra controls | Outside the main five-arm bill. Report any input draws, exact unit or fixture scope separately, including what was omitted. |
| Independent effort | Record independent role execution times, files and replay work. Public DRAND and local infrastructure are distinct from the synthetic ledger. |

All studied normal arms independently undergo the same lawful applicable guard check. An (n)-attempt series has acquisition-only cost equal to actual paid ledger plus its separately identified one-time guard receipt. Its amortized setup charge is (1/(4n)) per attempt where that check suffices and is reused, with actual compilation and work costs still separately recorded. Stylized numeric costs do not represent real billing. Historical X12 preserves its cheaper and more powerful direct-access result.
