## 3. Research reconstruction

Final Theorem Package pp. 7–11 defines evidence-relative target sets, the frozen query interface, disagreement edges, audit inaccessibility and the global and realized weighted costs. Two equal-answer contracts with different targets defeat every available sequence of these deterministic queries. A uniform audit separates every target-distinct pair, whereas a realized audit needs only to distinguish the supplied completion from alternatives with a different target. Conditioning by actual observed answers is required for a realized certificate. Choosing a cheaper realized audit presupposes an actual completion for this experiment's oracle computation, so these optima are unavailable as advance policies without further premises.

The explicit hitting-set optimizer and a direct powerset partition oracle use distinct representations. Exhaustive comparison will check status and optimality and verify sufficiency for every subset. Charter pp. 15–17 motivates the paired-completion test and a later counterexample-guided synthesis. The present finite experiment uses explicit hyperedges with reduction. Symbolic or lazy scalability remains X05's obligation. The original PC evidence, representation and authority coordinates determine closure touch in the structured controls and remain distinct from the acquired query answers.
