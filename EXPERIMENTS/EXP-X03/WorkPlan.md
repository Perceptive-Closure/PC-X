# EXP-X03 — Global and local certificate optimality

## A. Scientific objective

Can a weighted semantic audit engine produce globally sufficient and realized minimum-cost certificates? Test T04–T07 and the finite oracle assumptions of T14. The hypothesis is zero disagreement with independent exact partition and optimum checks for the frozen interface. This establishes bounded correctness, including genuinely distinct sufficiency and cost meanings. It leaves operational scalability and strong separation families open.

## B. Scope

Write under `EXPERIMENTS/EXP-X03/`. Use explicit finite, possibly multi-valued answer tables and positive integer query costs. Include structured PC-compatible semantic fixtures with independently derived authorization freeze targets and generic combinatorial stress cases. All actions and data are local and inert. Prefer standard-library Python 3.13. No query that directly returns the target.

## C. Mathematical specification

For every target-distinct pair, the disagreement edge contains exactly queries on which their answers differ. A uniform certificate hits every edge. A realized certificate for C hits only edges incident to C. An empty edge expresses audit inaccessibility in the relevant scope. A nonempty homogeneous domain yields cost zero. Empty evidence is inconsistent. Compare scoped hitting sets to direct conditioning and partitioning under each subset. For a declared extensional equivalence, compare target identification against full contract recovery. Keep ties, uniqueness, inclusion minimality and minimum weighted cost distinct. Provide non-cheaper proofs for exact outputs and witness validation for insufficiency.

## D. Methodology

Freeze costs, generated family strata, seeds and output metrics before running. Include weight traps, a strict local/global gap, multiway queries, observationally aliased targets and target-homogeneous multiple full contracts. Use exact power-set search based on direct partitions as a reference, greedy separation, simple inclusion-minimal deletion, exhaustive querying and seeded random acquisition as comparators. Run query, cost and answer perturbations with expected failure or altered result. Use hyperedge reduction or a lazy exact pair oracle as the optimization subject. Sampling represents workload coverage, so distinguish it from population inference.

## E. Implementation

Provide a callable evaluator, JSON/CSV input or frozen included fixtures, exact and baseline algorithms, corruption tests, an independent verifier, raw per-case optimum and cost metrics, and deterministic regeneration/check commands. Fully disclose query legitimacy for operational fixtures. Include test cases intended for X04 and X05 method reuse or validation.

## F. Acceptance

Zero unexplained cost or feasibility differences for uniform and all realized cases in the tractable corpus. Check certificates and impossibility witnesses independently. Record cases with multiple optima, strict local versus global differences, and failures of each relevant baseline. Measure both correctness and acquisition cost without comparing incompatible interfaces. Leave open any claim of general algorithmic advantage that the data cannot establish.
