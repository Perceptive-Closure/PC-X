# T30.U boundaries and counterexamples

| Boundary | Witness and exact consequence |
| --- | --- |
| U.2 requires likelihoods | One bit is \(\mathrm{Bernoulli}(1/4)\) versus \(\mathrm{Bernoulli}(3/4)\) in two worlds with identical fixed physical state after the bit. The two world supports and per-world physical point masses coincide at both records. With the bit a test attains \(1/4\) uniform error. Any final test using either coarser summary gives worst error at least \(1/2\). |
| U.1 requires global worlds | There are only two licensed nonnegative hazard profiles \((q,0)\) and \((0,q)\) over two successive independent hazard opportunities conditional on the installed profile, with \(0<q<1\). The worst union probability is \(q\). Independently maximizing the two rows inserts the absent combination \((q,q)\) with risk \(2q-q^2>q\). An exact world with the higher value is missing. |
| U.3 is unconditional before selection | Take an issuance event \(I=B\) of probability \(\eta>0\) and a physical violation on all its mass. The covered cases never activate and satisfy the numerator inequality. \(\Pr(V\mid I)=1\) despite arbitrarily small \(\eta\). |
| Selective risk differs from whole-attempt risk | The routed protocol in U.4 has feasible joint risk \(2/5\), usefulness and \(\delta\) after scoring. Since every pre-verdict tape in a positive world is possible in a matched negative world, requiring \(2/5\) on every activated world eliminates all nonzero useful coverage. |
| U.4 requires exact event binding | If the dry harness always uses threshold 1 and the live stage instead permits threshold 1 or 3 in otherwise matching worlds, all complete audit laws coincide while live reference risks are \(1/4\) and \(3/4\). A changed instrument cannot certify the protected live law by its visible tape. |
| Useful receipt and literal callability | Two modes require disjoint finishing calls. Remove the actual intake receipt or relabel those different calls by a single projected word. The shared controller cannot execute either literal at the resulting ambiguous record. The two known-mode routes remain useful. |
| Free initial mode reveal | Add the legitimate actual label at the first record. The same routing work now needs zero price and zero identification error. This is a change of information interface, so it defeats the old lower bound only for the altered class. |
| Support omission | At a genuinely authorized audit action insert an independently checked probability \(1/10\) of a real terminal violation with the same public receipt as its safe outcome. A solver that omits it can advertise zero risk. If the action changes \(R\) on that branch the whole occurrence is excluded under the R freeze. Top-level support verification cannot be replaced by one sampled branch. |
| Retained carry and post-certification effects | A protocol can let the responder set a hidden bit on issuance and choose live thresholds 1 or 3 based on it. The original dry row survives verbatim. The actual post-certification risk changes. Including the bit and the allowed continuation is essential. |
| Useful coverage and scope | Refusing all activation has no operational risk in the routing fixture and gives \(G=0\) on every positive world. The declared \(\mathbb E G\ge1-\delta>0\) and uniform binary error reject it. Source membership for every admitted low-level operation still needs independent checking. |
