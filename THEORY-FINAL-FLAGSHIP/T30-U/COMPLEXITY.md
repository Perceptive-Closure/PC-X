# T30.U complexity

Let \(M\) be the total number of represented hidden world-state pairs, \(A\) the maximum literal action count, \(O\) the maximum recorded outcome count, \(Q\) the number of reachable time-indexed posterior states, and \(J\) the total number of affine world constraints. The explicit-tree realization LP uses a variable for each admissible action at each controller record and equalities along histories. Its data include exact per-world conditional chance products. A rational LP is polynomial in that encoded representation and its coefficients. It need not be polynomial in the original source.

The compact graph uses at most \(QA\) state/action flow variables and \(O(QAO)\) distinct recorded edges before merging. The direct dense construction uses \(O(QAOM^2)\) exact rational additions and multiplications, up to input parsing, exact hashing and the additional finite mask/record checks. Stage and terminal metric coefficient construction can scan the same kernels for each declared reward coordinate. In the common finite arithmetic model a common denominator \(D_t\) of all probabilities in a layer can be chosen as the product of their input denominators. Each hidden numerator for an observed prefix has denominator dividing \(D_0\cdots D_t\) and has mass at most one before normalization. The posterior coordinates are ratios of such integer numerators, so their bit lengths are polynomial in cumulative expanded input bit lengths and horizon. Repeated computation can reduce fractions and compare exact tuples. Code checking the structure, world membership and correspondence is additional source-verification work. Replaying one policy does not establish an exact source class.

The product bound in U.2 is polynomial for fixed world count, hidden-state sizes and row-likelihood vocabulary, and polynomially bounded public registers. It is a numeric-horizon bound. Plan compression can fail when those constants scale, when latent dynamics are not unifilar, when probabilities live in a continuum, or when a path-dependent requirement needs a large statistic. Merging all past histories having the same world support can discard likelihood ratios and lose optimality. A separate posterior for each world over its physical states, without relative world likelihoods, has the same problem.

A hard paid-price threshold test is an extra zero-exceedance constraint. If its accumulated-price register is absent, testing by path sums can require the expanded representation. Do not infer a bit-polynomial hard-price algorithm from an expected-cost flow LP. In the routing family the prelude has exactly \(t+1\) distinct states at depth \(t\), at least \(2^t\) distinct histories, and a fixed-size finishing gadget. Computing all reachable prelude layers therefore has \(O(N^2)\) states with polynomial coefficient sizes and a polynomial rational optimization. This is a represented structural bound with matched probabilities and payoff constraints. It makes no general computational superiority claim.
