# Assumptions and status boundaries

| Condition | Warrant or failure disposition |
| --- | --- |
| Actual initial and conditional laws are in the candidate representation | Check admitted source and calibration evidence. Otherwise report missing correspondence. |
| Authority and hard budgets apply to all positive branches | Verify literal source occurrence and extensional changes. An unseen branch carries its declared consequences. |
| Communication and role records are explicit | Check cues, available commands, retained memory and whether an audit alters the process. |
| Intrinsic goals are fixed | A certification announcement can affect actual future behavior, which its authorized continuation model must include. |
| Cost objective is fixed before optimization | Separate hard limits, maximal path charge, worst expectation, prices and resource/accounting overhead. |
| Phase risks and issuance meanings are fixed | Report conditional guarantees only for positive issuance mass or with explicit coverage. |
| Sound overapproximation and exact realizability differ | A robust cover suffices for soundness. Its extra worlds may produce conservative lower or inverse claims. |
