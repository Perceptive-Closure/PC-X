# Counterexample ledger

Each witness indicates the assumption that was weakened. The immutable experiments and the additional finite proof exercises have separate provenance.

| Boundary | Witness and effect |
| --- | --- |
| Empty evidence | An empty compatibility set vacuously satisfies universal equality but has empty exact target image. A certificate must first produce or verify existence. |
| Extensional representative | In the D-35 pure R completion an admitted representative has no direct compatible world. Its larger cell does. Requiring $H(s)$ alone to be compatible incorrectly rules out the candidate. |
| Privileged interface | Two aliased physical states enable different useful actions. Per-state "winning" and local renaming give an illusory common policy. Public action maps must be consistent and injective on the relevant alphabet, with a common callable lift in T30.S. |
| Distinct outcomes at equal observations | Hidden states can produce different visible readbacks even when their checkpoint observation is equal. Merging outcome labels discards a lawful information channel. |
| Zero-cost loops | One open state with one zero-price self-loop satisfies a Bellman equation with value zero and has no proper closing tree. |
| Whole supported touch | If one possible successor changes R, freezing R removes the entire source atom. A first-successor-only check or a fabricated partial move changes the underlying intervention. |
| Correlated completions | XOR across two competing unit repairs gives actual $\{1\}$ while a rectangular product creates infinity. Two correlated serial modes (0,0) and (1,1) can have opposing target values and no legal one-coordinate crossing. |
| Budget pruning | A cheaper larger support may fit the parent budget while a smaller expensive support does not. Antichain pruning must use the same residual budget. |
| Costs that depend on history | A constant answer can still unlock a price change. If it costs 1 and discounts a later distinguishing readback from 10 to 1, discarding the non-split action on a belief-only model loses the optimal policy. This is a different legal transcript state. |
| Binary weights | The serial paired oracle includes SUBSET SUM with a residual one-unit pivot. Numeric DP budget length and query acquisition cost are separate. |
| Infinite pointwise decidability | For candidate $n\ge0$, the bit that a fixed machine halts within $n$ steps is pointwise decidable. The question whether the entire nonempty set has both bit values decides eventual halting after padding the machine with one initial step. Pair existence needs a complete finite/oracle premise. |
| Threshold nonattainment | For $n\ge2$, risks $1/2+1/(2n)$ all fail the threshold $1/2$. Their infimum equals the threshold and is unattained. Attainability affects the lower-bound shortcut. |
| Initial information | Opposite targets can be observable in model-dependent initial labels at zero paid probe cost. Stopped KL includes that information. |
| Adaptive issuance | If a rule issues only on a model's exceptional event of probability $\delta$, joint wrong-issuance error can be $\delta$ with conditional error 1 among its issues. |
| Confidence-rule conflation | A tiny mixture weight keeps both Bernoulli hypotheses alive on every all-zero prefix through 32 samples even though the separate histogram sample cap is smaller. Use the correct procedure. |
| Auxiliary readings | Equal Bernoulli score marginals and equal auxiliary marginals do not imply equality of the joint response. Positive vs negative correlation gives disjoint pairs. |
| Monitor and fidelity | Constant public alarm/tape can hide different independently scored outcomes, including when a probe replaces the actual scoring mechanism. Omitted contexts can bear arbitrary mass. |
| Composition | Individually valid locals do not rule out a new global event. Actual joint local bounds can also cease to be valid even when containment survives. |
| Higher-order readiness | Each of $n$ one-step installations rules out a unique lawful job command. Every proper subset can complete shared work. The whole set cannot. |
| Free installed mode | Reporting a deployment's current fast menu may disclose the mode at zero cost. T30.S instead validates a conditional lookup rule and accounts for all prior publicly available evidence before optimizing. |
| Refusal | A policy that stops without work may be safe on every supported path and fails the nontrivial service target. |
