## Common finite-policy argument

Write $B$ for the nonempty set of physical checkpoints compatible with an observable prefix. The next action must lie in $\bigcap_{s\in B}Q_F(s)$, where $Q_F$ is the surviving menu. For any selected $q$ and signal $\ell=(y,o)$, the next belief is
$$
B_{q,\ell}=\{u:\exists s\in B,\ q\in Q_F(s),\ u\in N(s,q),\ (y(s,q,u),\omega(u))=\ell\}.
$$
In the resource kernel with explicitly labeled pairs, the same formula uses every supported pair carrying $\ell$. Only nonempty updates are branches. This construction unions all physical successors for a given public signal. Even when two hidden branches produce the same public label, neither may be removed. A belief permits Stop when $B\subseteq G$. This uses the sealed definition of stopping at physically closed leaves. It does not require that their closed labels agree.

Induction on the prefix gives the exact compatible set. Consequently, any continuation tree legal from a belief can be transferred to a second occurrence of the identical belief. A cost is known once the action is selected. If an ancestor and a proper descendant on a branch have the same belief, copy the descendant's continuation over the ancestor's subtree. Its supported continuations are identical to those it had at the descendant. The cost saved along the route to the descendant is nonnegative. The maximum cost of the new subtree is no larger than the old maximum, since every physical continuation through the descendant already counted towards that maximum. The number of tree nodes decreases. In the fixed kernel the set of used physical occurrences also shrinks, because all copied continuations were possible from the same belief in the original. Repeating gives a tree with no repeated belief on a branch. The number $h_\star=2^{|S|}-1$ of nonempty subsets of $S$ is a safe action-depth bound. Every positive-support state in the belief arises after that same prefix, so this replacement does not assume independence of hidden states across time.

There are finitely many trees of height at most $h_\star$, since the action and outcome alphabets used by the finite kernel are finite. The cost infimum is attained when finite, also for nondiscrete real action costs. Let $J_0(B)=0$ for $B\subseteq G$ and $J_0(B)=+\infty$ otherwise. Then
$$
J_{j+1}(B)=
\min\!\left(J_0(B),\
 \min_{q\in\cap_{s\in B}Q_F(s)}
  \left[c(q)+\max_{\ell:B_{q,\ell}\ne\varnothing}J_j(B_{q,\ell})\right]\right).
$$
An empty action minimum is $+\infty$. This is the height-bounded optimum by induction, with each public child requiring its own legal continuation. It descends from $J_0$, and is exact at $h_\star$. Its finite-value sets give the stated least Boolean attractor of all-closed beliefs followed by beliefs with an admissible action whose updates all already win. An open state with a zero-cost self-loop and a cost-one exit to a goal has equation $v=\min(v,1)$ and proper optimum $1$. The algebraic solution $0$ does not give a proper policy. A zero-cost loop with no exit has no proper policy at any height.

When comparing deletion masks, a policy that is legal after deletion has the same beliefs and positive-support successors as when replayed before deletion. Indeed the selected action was available at every state in its current belief, and all its supports there were retained. This proves monotonicity of value under mask inclusion. Guessing that a removed action occurrence could instead eliminate just that hidden branch would change the model.

## T08 · Adaptive minimax and product identification

At a constant target cell Stop is free. At a nonconstant cell a first nontrivial query must split the cell. A nonsplitting query has a forced answer and adds positive cost, so contracting its node preserves determination. Every child of a split is a smaller nonempty cell. Applying induction on $|B|$ gives the stated minimum of the query price plus the maximum optimal child cost. Conversely choosing a minimizing split and an optimal subtree at each child constructs the proper tree whenever the value is finite. If no split exists in a nonconstant cell the target is not obtainable. A randomized first choice cannot improve the infimum over deterministic choices when every supported random branch counts towards the worst cost. Equivalently couple the random seed across contracts. For finitely many inputs, a zero-error almost surely terminating policy with finite worst-supported cost has a common full-measure set of seeds on which the determinized policy is correct and stops on all inputs, at no larger maximum cost.

For Cartesian products and disjoint local query menus, a uniform static audit has to determine each local target from the local projections of the queries. This follows by varying one coordinate while fixing all the others. The same argument at a specified tuple gives the realized requirement. Uniting local optimal sets gives equality in each static sum. Concatenating local optimal trees is an adaptive upper bound.

For the adaptive lower bound the posterior remains a product of local cells $B_i$. If one factor is inaccessible, an indistinguishable local conflicting pair and fixed choices of the other factors give a global collision. Otherwise all the local cell optima $V_i(B_i)$ are finite. At any local query $j$ in coordinate $i$, one realized answer has $w_j+V_i(B'_i)\ge V_i(B_i)$ by the Bellman inequality and the worst-child choice. This also holds for a nonsplitting query and every other potential is unchanged. Along a branch choosing such answers the accumulated cost plus the sum of residual potentials cannot decrease. At a correct leaf every local target is constant, so every potential is zero. The branch arises from a nonempty product cell. The original sum is therefore a lower bound on worst cost, even for interleaved local queries.

A unit-price query returning two factor bits at once violates the disjoint local-menu premise and can cost one where the two separate bit audits cost two. A correlated domain with $x_1=x_2$ has the same failure of additive optima even with disjoint bit probes.

## T09 · Hierarchy and routed separation

An exact bit probe reads the local routing setting. The derived frozen local costs are the planned binary values. The optional shortcut makes the effect of the freeze substantive and does not change the proof. Polynomial work in the numerical budget is pseudo-polynomial; a budget encoded in $L$ bits can be of order $2^L$.

## T11 · Correlated freeze envelopes

Let $\mathcal P$ be the nonempty family of compatible eight-mask profiles. When only masks vary, every mask is a subset of a finite occurrence set. Hence the support of $\mathcal P$ and the image through $\kappa$ are finite, whether or not the underlying source-description family is finite. The exact identified coordinate set is the image of its projected masks. Deletion monotonicity gives
$$
\kappa(\cap_C M_F(C))
\ \le\ \min_C\kappa(M_F(C))
\ \le\ \max_C\kappa(M_F(C))
\ \le\ \kappa(\cup_C M_F(C)).
$$
Admissible endpoint masks suffice for equality. Equality can hold without them: use a cost-one always-surviving closer and two more expensive routes, with only one of the two backup routes $R$-masked in each completion. Both bounding masks and every compatible mask leave the cost-one route, although neither bounding mask is admissible.

For both bounds strict, make two stages with a cost-one and a cost-two local route each, each with its own intermediate checkpoint. All stage states are open, each route joins the same next stage at zero extra cost, and a pure-$E$ zero-cost suffix closes. Give the two worlds and histories the universal open and unanimous closing compatibilities. Flagging a route in a completion changes the equivalence relation on off-cell histories at its intermediate checkpoint, with the relation restored on leaving that point. Exactly the two supported actions along that route touch $R$. In one completion flag stage one's cost-one route and stage two's cost-two route. In the other flag the complementary routes. The two masks are disjoint, each forces frozen cost $3$, their intersection has value $2$, and their union yields $+\infty$. The shared kernel and ordinary source locators remain fixed.

For joint signatures the $E$ and $R$ coordinates of the T02 single-route pair are $(+\infty,1)$ and $(1,+\infty)$. The product of their separately attainable sets also contains $(1,1)$ and $(+\infty,+\infty)$, neither attainable in this evidence family. Keeping profile-level correlation prevents this artifact even when each coordinate set is known exactly.

If admissible profiles are decidable, enumerate tuples of masks and retain the admissible ones. Compute each coordinate by the belief horizon, collecting profiles for the resulting signature. This returns witnessing profiles without relying on independent coordinate choices. It need not return a concrete source completion unless that witness is available as well. With varying real costs, even one sure closing action with cost restricted to the open interval $(0,1)$ has both unattained endpoints. Infinite frozen values also arise structurally from the absence of a proper closer with finite action costs.

## T12 · Closure supports and intervention blockers

For a legal policy tree at belief $B$, its root action $q$ contributes the occurrences $\{(s,q):s\in B\}$. Each of those states lies on a positive-support trajectory through that prefix and extends to a leaf. The tree's support is the union over all its nodes. A budget-feasible tree survives deletion if and only if its support is disjoint from the mask. In the reverse direction a tree built after deletion can be replayed before deletion with the same beliefs, leaves and cost, as proved above. The finite support ground set ensures that any feasible support contains an inclusion-minimal feasible one.

It follows that a mask destroys every budget-feasible closer exactly when it hits every element of $H_b$. To see the blocker identity directly, every $U\in H_b$ hits every minimal transversal of $H_b$. A set $W$ containing no $U\in H_b$ has a complement that hits $H_b$, and that complement contains a minimal transversal disjoint from $W$. Thus the minimal sets hitting the blocker are exactly $H_b$. If there is no budget-feasible closer, $H_b=\varnothing$ and the unique minimal destructive mask is the empty mask. If the empty support is feasible, $H_b=\{\varnothing\}$ and no mask can destroy closure. A negative budget, if allowed, leaves no feasible support. These set systems concern allowable abstract whole-occurrence deletion, and a minimal abstract blocker need not be a mask licensed by a given source contract.

The repeated-belief pruning argument preserves the budget and takes a subset of the original support. In particular any minimal support of a feasible tree already has a witness of height at most $h_\star$. An exact generation recurrence uses the antichain $K_j(B,t)$ of minimal supports at a specified remaining action height $j$ and remaining budget $t$. For $t\ge 0$, a closed belief has antichain $\{\varnothing\}$. At $j=0$ an open belief has empty antichain. For each action $q$ that is admissible and costs at most $t$, choose one continuation support from $K_{j-1}(B_{q,\ell},t-c(q))$ at every nonempty signal update. Union them with the root occurrences and minimize by inclusion among the unions across all such actions. With a missing required continuation the action contributes no union. Substituting a smaller continuation support within the same budget and height cannot harm the root budget or enlarge the union, giving the induction. One can instead keep pairs of support and cost and prune only when both inclusion and cost give dominance. There is no requirement that the family or the set of residual budgets be small. In a deterministic chain of $n$ stages with two independent cost-one actions to the next stage at every stage and budget $n$, all $2^n$ minimal policy supports appear.

The remaining budget is a consequential qualification to inclusion pruning. Consider a prefix action of cost $4$ reaching $h$. At $h$ a zero-cost fork visibly reaches $p$ or $q$. From $p$, a zero-cost action with one visible label reaches hidden belief $\{r,t\}$. From $q$, a cost-four action reaches $\{r\}$. The states $r,t$ share an observation. Both enable Slow, cost $5$ to a goal. Only $r$ enables Fast, cost $1$ to the same goal. All earlier checkpoints are open. From $h$, using Slow at both beliefs has worst cost $9$ and gives a support $U$. Using Fast at $\{r\}$ alone still needs both Slow occurrences at $\{r,t\}$; it adds $(r,\mathrm{Fast})$ to $U$ but costs $5$ at $h$. For root budget $9$, a recursion minimizing inclusion at local budget $9$ for $h$ would discard that larger support and find no feasible root tree. Minimizing at residual budget $5$ preserves it. The generation claim holds with the cost-aware interpretation, and fails under unconditional inclusion pruning.

## T13 · Constructive ambiguity or certificate

Verified infeasibility of the source constraints yields INCONSISTENT. For a verified compatible $x$, query the pair oracle with no equal-answer conditions. A verified no-conflict proof yields IDENTIFIED with value $f(x)$. A checked conflict establishes nonidentification. At that point a full-menu pair query distinguishes the following outcomes.

- A verified whole-interface conflict yields AUDIT-INACCESSIBLE by T05.
- A verified exclusion of whole-interface conflicts yields UNDERIDENTIFIED, together with the checked first pair to witness the conflicting targets. The whole menu could determine the target, while the present evidence leaves multiple values.

For a multivalued target, a conflicting or opposite target is a different target value. A pair independently verified at either step also proves feasibility. If a required proof is missing or does not check, report UNKNOWN for any remaining classification. A checked pair can still certify nonidentification while accessibility remains unknown. A no-conflict report for the full menu alone proves accessibility on a nonempty class, while current identification still requires testing the empty set. A no-conflict report for the empty query set without verified feasibility cannot distinguish consistent identification from an empty class.

All tests here are exact quantified oracle calls. Pointwise computability is insufficient on an unbounded domain. For a given machine $M$, membership of a natural number $t$ in $\{t:M\text{ halts within }t\text{ steps}\}$ is decidable by finite simulation. An exact emptiness checker for every such class would decide whether $M$ ever halts. Even if an always-present point of target $0$ makes class feasibility immediate, adding a target-$1$ point for every such $t$ makes existence of a conflicting pair undecidable in general.

## T14.a · Implicit minimum audit synthesis

First establish feasibility as in T13. Let $\mathcal H$ initially be empty, and solve the weighted transversal problem on its current edges exactly. Its optimum is a lower bound on the true uniform certificate optimum. A returned pair agreeing on the selected set $J$ is checked for feasibility, distinct target, and equal answers on $J$. Compute its whole disagreement edge $D$. If empty, it certifies inaccessibility. Otherwise it is disjoint from $J$, so it differs from every previously recorded edge, since all those edges meet $J$. Add $D$ and repeat. A certified no-conflict result makes the candidate valid by T04. Together with the lower bound this proves optimality. At most $2^m-1$ nonempty additions are possible. With exact solvers and verified outputs, at most $2^m$ pair checks after feasibility suffice for a conclusive termination. At $m=0$, the only possibilities on a nonempty class are a constant target or an empty disagreement edge. An incomplete or unverified answer cannot establish a missing bound or no-conflict result. If candidate feasibility is verified independently, it remains evidence of a certificate even while minimality is unknown.

## T14.b · Product localization and attainable contexts

First, for the serial resource interpretation at a fixed assignment, a local optimum concerns reaching the common next entry from the current exact entry belief. If the local values and final suffix are finite, proper local optima can be concatenated, giving overall cost at most the sum. Conversely, any proper global tree restricts after any reached prefix to a proper local exit policy and then a proper residual global policy. The entry belief at the interface and the next capability/support are fixed across prefixes. An adversary can choose a supported local worst-cost prefix through the current stage, and then the same lower bound applies to the next stage conditional on that prefix. Induction gives a global branch costing at least the sum of the local optima, including the fixed suffix. If any local stage or suffix has no proper closer, a proper global tree would contradict that failure at its common entrance. This uses that the intermediate checkpoints are open and all possible branches execute each stage. A path-dependent hidden carry across the interface would invalidate the argument.

For fixed selected $J$, suppose two compatible product assignments agree on the selected answers and have different targets. Replace coordinates of the first assignment by the second one at a time. The full product keeps each hybrid compatible, and local queries keep its selected answers fixed. Some adjacent pair in this chain changes the target. The converse follows because a compatible single-stage pair is itself global. At stage $i$, define $u=\min(v_i(z),v_i(z'))$ and $v=\max(v_i(z),v_i(z'))$. An edge from that pair is relevant precisely when an attainable outside sum
$$
T=\tau+\sum_{k\ne i}v_k(z_k)
\quad\text{satisfies}\quad
T+u\le b<T+v.
$$
Then its disagreement set is confined to $Q_i$. Covering all such local edges is necessary and sufficient by the hybrid argument and T04. Independent local transversal minimization therefore adds. An empty required edge makes the optimum infinite. For identity the same product argument gives all distinct local-mode edges regardless of scores.

The two optima can coincide. For $n\ge 1$ take two local modes of costs $0,1$ at every stage, one bit probe per stage, and use $b=\tau=0$. Each stage can change the target with all other stages at zero, so each bit is necessary both for this target and for full identity.

For edge generation let $\operatorname{cap}(v)=\min(v,b+1)$, with $+\infty$ mapped to $b+1$. Using nonnegative scores, capping before or after each addition gives the same final cap and preserves threshold comparison. For each $i$, a Boolean table for sums outside $i$ starts at the capped suffix cost. For each other stage replace each current index by the capped additions over that stage's listed modes. There are $b+2$ indices at each step. Scan its attainable indices against each ordered or unordered local pair to build the edge family and keep witnesses. This uses pseudo-polynomial preprocessing in $b$ and polynomial work in the sizes of the local tables and encoded prices. Given those edges, test the $2^{|Q_i|}$ local subsets at each stage and select the least price among hits of every edge.

A paired oracle can instead enumerate the attainable capped pairs of sums. At a stage, partition its modes by the selected answer tuple, and assign each cell the pair consisting of its minimum and maximum cost. Replacing a same-answer left and right mode with the respective cell extrema preserves any possible left-low/right-high threshold separation. The two coordinates must come from the same local cell. From these paired extrema choices add capped scores coordinatewise, including the suffix. Within any intermediate stage retain only pairs undominated for minimizing the left sum and maximizing the right sum. Coordinatewise capped addition is monotone, so a dominating pair preserves both sought inequalities for every future choice. A surviving witness selects actual extremal modes and can be recovered from predecessor pointers. Taking the first threshold-flipping step in its product hybrid gives a compatible single-stage witness.

Correlation breaks both the hybrid and independent cost guesses. With only assignments $(0,0)$ and $(1,1)$, local costs equal to the bits, and $\tau=b=0$, the unqueried target conflicts but no pair differs in one feasible stage. With only assignments $(0,1)$ and $(1,0)$, each marginal local minimum is zero, but no assignment reaches overall budget zero. A cross-stage query returning both bits for one price also defeats independently adding local query prices.

## T14.c · Bounded-width paired oracle

Replace stage variable $z_i$ by $(z_i,z'_i)$ on its product domain of size at most $d^2$. Enforce selected local-query equality on the paired variable. For each given factor, assign it to one bag containing its scope and test the constraint on each copy of the assignment in that bag. Both assignments must be compatible, but may differ. Orient the wanted pair with left total at most $b$ and right total greater than $b$. Cap both cumulative costs at $b+1$ as above.

At a bag keep Boolean entries indexed by the pair assignment of its vertices and both scores of variables already forgotten in the subtree. An empty leaf starts with zero scores. At an introduce node extend the bag assignment and keep the inherited scores. At a forget node remove the variable from the bag and add its two scores, once, before capping. At a join take child entries with the same bag assignment and add the two capped scores coordinatewise. The forgotten variables from distinct join subtrees are disjoint by the connectedness condition on bags. These rules preserve existence of extensions satisfying the factors assigned within the subtree. For a cost factor involving multiple variables, if present, count its two costs once at its chosen factor bag instead of assigning that cost to each vertex forget. At the root account for any remaining bag variable costs and the fixed suffix, then compare the thresholds. Backpointers reconstruct the two actual global assignments and thus a verifiable witness.

A bag has at most $d^{2(w+1)}(b+2)^2$ entries. Joins cost at most $(b+2)^4$ candidate score-pair combinations per common bag assignment. Other node types need at most one update per source entry or extended entry. This gives $O(Nd^{2(w+1)}(b+2)^4)$ table updates for the supplied nice decomposition, apart from local factor lookup and arithmetic. At fixed width and suitably bounded numeric budget the oracle is polynomial in the tabulated input. Outer optimization can still be NP-hard even at width zero and $b=0$: use a single stage whose tabulated mode domain is the T10.a incidence table, with score $0$ for one target class and $1$ for the other. The oracle for a fixed selected set is polynomial there, while selecting a minimum subset still solves the covering instance. This example allows the local domain and local query count to grow as in the sealed bound.

## Issues reserved for comparison

The derivations cover the sealed mathematical models. T12 needs residual-budget-indexed inclusion or cost/support dominance for its generation algorithm. T10.b's NP-completeness is for a compact stage input, whereas the listed-table pair problem is polynomial in the materialized input. T08 product additivity and T14.b localization need their product and disjoint local-menu premises. T03 uses uniform public renamings. None of the abstract mask or oracle constructions establishes that a particular deployment has licensed source semantics, a certified pair oracle, or the required compatible family.
