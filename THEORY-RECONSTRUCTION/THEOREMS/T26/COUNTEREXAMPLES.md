
# T26 · Fidelity and informativeness counterexamples

1. **Faithful and uninformative.** Use a finite one-tick target with a nonconstant true event. A logger records a fixed symbol without changing any row or any policy input. Its erasure certificate has zero error, and its reported symbol identifies no hidden event occurrence.
2. **Perfect measurement of a changed plant.** The original machine safe state always stays safe. An instrumented switch forces a known dangerous outcome and reports that outcome without error. This gives a perfect true label for the instrumented law and risks 0 and 1 for the two plants. An accurate probe does not license a claim about the unchanged plant.
3. **Equal displayed traces, failed retention.** Output the same public acknowledgement in both plants under every allowed request. Reserve the sole virtual service slot only in the instrumented plant. With a fixed job each tick, a trusted cumulative backlog scorer distinguishes the plants even though the displayed acknowledgement sequence is identical. The projected physical rows differ.
4. **Extra feedback changes the controlled law.** Let an initial concealed bit decide which action makes one deterministic completed move safe. A passive device stores that bit without changing the two possible action rows. The source policy has one prior observation and uses a fixed act. An instrumented controller reading the extra bit can choose each matching act. Erasing it preserves the original action law, but using it changes the policy and can improve risk. Exact row equality alone does not justify transporting this new controlled law.
5. **The product bound can be attained.** Let the reference never fail. Let the projected probe begin with an absorbing failure with probability $\eta_0$ and acquire that irreversible failure with conditional probability $\eta_{t+1}$ in each step still matching. Score failure at the end. All local caps attain equality and the risk difference is exactly $1-\prod_i(1-\eta_i)$. Keeping the event bit is essential to this comparison.
