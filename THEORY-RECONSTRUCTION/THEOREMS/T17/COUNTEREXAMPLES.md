# T17 · Boundary cases

Bernoulli(1/3) and Bernoulli(2/3) have distinct laws and every identical finite bit string is possible under both. Infinite-data law identification is possible while a finite zero-error forced decision is impossible. For the embedding, assigning probability zero to an unsafe original supported successor can turn a structurally impossible zero-risk repair into a false passing result.
