# T19 · Exact risk classification and cost comparison

For any nonempty compatible class, set S to the image of r, so each s in S has a realizing completion. All risks pass if every s≤ε, equivalent to sup S≤ε because ε is then an upper bound, and if the supremum is at most ε every member is also at most ε. All fail exactly when no s≤ε. If inf S>ε this is automatic. If inf S=ε, the only possible passing point is ε itself. If inf S<ε, the definition of infimum provides some s<ε. This proves the failing condition with the attainment qualification. If neither uniform condition holds, there is a passing and a failing completion. The interval [inf S,sup S] is the smallest closed enclosing interval, but values in the interior need not be present. If the class is empty, it is inconsistent and no probability claim follows. A finite nonempty image supplies extremizing witnesses by enumeration. If deployments within a completion have an unattained risk supremum, the risk target is the supremum by definition, so this does not license removing the threshold equality case.
