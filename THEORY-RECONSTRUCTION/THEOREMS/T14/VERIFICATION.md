# T14 verification

## Independently checked scope

T14.a is exact implicit weighted hitting set given a complete oracle. T14.b localizes serial product crossings. T14.c bounds the paired oracle on supplied width and numeric budget, with one charge per factor variable and separate outer cover cost.

The parent accepts this scope after the sealed independent derivation, exact comparison and separate hostile review. ## Constructor checks

The code checks 1,280 two-stage scores/budgets, 5,120 width-one correlated paired instances with an actual join and infinite scores, and explicit premise failures. All computations compare small exact tables, not native or performance experiments.

The deterministic finite challenge script is [check_candidates.py](../../WORKSTREAMS/exact/check_candidates.py). Matching a finite challenge is auxiliary evidence. The hash-pinned sources and retrospective experiment links are in [EVIDENCE.md](../../WORKSTREAMS/exact/EVIDENCE.md).

## Independent proof and hostile review

A distinct reviewer should first record a fresh derivation of the sealed [statement packet](../../WORKSTREAMS/exact/STATEMENTS.md), then check the [proof packet](../../WORKSTREAMS/exact/CONSTRUCTIVE-PROOFS.md) and challenge the premises using [Counterexamples](COUNTEREXAMPLES.md). The parent records independent decisions. This constructor commits a candidate only.
