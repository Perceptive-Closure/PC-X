# T18 · Boundary cases

**Missing actual event map.** Two devices emit the same public success symbol and different independently scored receipt bits at every tick, giving violation rates 0 and 1. Common lower observed rows alone cannot transport the target.

**Hidden state omitted.** The first bit is fair. In E the second bit copies it and in D the second flips it, so unconditional single-step sums coincide while the event of two ones has probability 1/2 versus 0. The conditional-state check excludes this.

**Legality omitted.** A command permitted in a reference configuration can be forbidden in the target even if all visible pre-action cues match. It then has no authorized target counterpart.

**Changed instrument.** A diagnostic uses reference cutoff on both readouts and reports zero seam change. The target cutoff differs, so measurement agreement imposes no lower bound on that genuine paired row. Likewise an unpaired newly enrolled context can dominate the worst risk. Both failures require separate support or fidelity evidence.

**Policy condition omitted.** The same unconditional frequency of two commands allows choices conditional on different undisclosed state. Equality when that omitted state is averaged out is insufficient to compare supported conditional events.

The case limits the affected generalization to its stated premises. Full-width experimental applicability follows the independently typed interface. [Proof and model](PROOF.md)
