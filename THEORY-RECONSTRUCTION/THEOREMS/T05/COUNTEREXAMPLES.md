# T05 assumption ablations and counterexamples

If two rows carry opposite targets and identical answers everywhere, every admissible first query returns the same answer. Repeat the same coupling at every choice, including stopping. Add a new legitimate query returning independently established distinguishing facts and the collision need no longer be present. The obstruction is interface-relative.

The shared [proof packet](../../WORKSTREAMS/exact/FINITE-PROOFS.md) gives the full dependencies and derivations. The counterexamples record the stated scope and do not change the accepted experimental protocol.
