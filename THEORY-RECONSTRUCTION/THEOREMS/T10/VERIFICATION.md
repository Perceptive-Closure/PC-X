# T10 verification record

## Constructor checks

Exhaustive controls cover 128 families of three-coordinate incidence hitting sets and 544 serial budget instances. Proof explicitly checks polynomial input conversion, equality edge conditions and NP membership.

The deterministic finite challenge script is [check_candidates.py](../../WORKSTREAMS/exact/check_candidates.py). Matching a finite challenge is auxiliary evidence. The hash-pinned sources and retrospective experiment links are in [EVIDENCE.md](../../WORKSTREAMS/exact/EVIDENCE.md).

## Independent proof and hostile review

A distinct reviewer should first record a fresh derivation of the sealed [statement packet](../../WORKSTREAMS/exact/STATEMENTS.md), then check the [proof packet](../../WORKSTREAMS/exact/FINITE-PROOFS.md) and challenge the premises using [Counterexamples](COUNTEREXAMPLES.md). The parent records independent decisions. This constructor commits a candidate only.
