# Sealed T15–T24 statements and dependencies

The original targets are charter §§17–28, pp. 18–27. These are exact constructor candidates. Assumed law and instrument anchors refer to a declared finite system. Quantification over compatible completions is always relative to the source projection and evidence. Sources may refute or restrict a candidate without changing the original charter.

## Shared types and PC embedding

A completion C has finite time-indexed machine state, a source projection and its source-atomic interfaces, initial and conditional transition laws for each declared context, a controller that reads only its admitted history, a separate evaluator with an authorized query/reset menu, an evaluator-visible transcript, a monitor that may see a different projection, and an independent trusted rule for the terminal event. A latent state may include memory, installed parameters and context. A law for one execution specifies when observations and actions are sampled. The full history of an audit includes its queries, observed responses, public authorization and any independent randomness used by the auditor, or a known stochastic audit kernel with the same choices at equal histories. No new invocation resets memory without a declared reset. Let D(C) be the nonempty declared deployment context domain where relevant, V(C,d) the actual violation indicator, r(C,d)=Pr(V(C,d)=1), r(C)=sup_d r(C,d), and Ψ(C)=1{r(C)≤ε}. Set ε∈[0,1]. An evidence class H is nonempty when making any affirmative target claim. The empty class returns INCONSISTENT.

For a finite complete D-35 PC contract C, choose a resource mask F. Each eligible edge has a positive transition probability with exactly the declared joint successor and observable-label support. Use the original lawful observation-history policies, original closed predicate, no partial action under freezing, and public nonnegative cost accumulation. Define violation at horizon n to mean failure to stop closed within n transitions and cost budget B. A zero-risk observation policy exists at horizon n exactly when a proper supported closer with depth ≤n and worst-branch cost ≤B exists. The infimum over B admitting such a policy at some finite n recovers the original F-frozen value, with an empty budget set yielding infinity. The eight-coordinate signature follows by repeating all masks. This embedding is qualitative in probabilities.

## T15 · Observable-history indistinguishability

For a pair of completions compared on a common lawful, finite-horizon audit interface, use every jointly admissible action at a public history that can be reached by at least one admissible common protocol in either model. Include initial observations and stop behavior. Equality of initial and all such conditional observation laws implies equality of each permitted combined adaptive protocol's transcript law, including randomized or early stopping protocols. Conversely, if each history and next action in this definition can be exercised by a common permitted finite protocol, equality for all such complete protocols entails equality of those conditional laws on positive reachability. Rows on null histories are unconstrained. If targets differ, no transcript-based procedure can distinguish the pair exactly. The statement includes repeated experiments only when the repeated protocol's conditional-history premises hold.

## T16 · Fixed implementation with an omitted deployment anchor

There are two finite governed completions of a single deterministic controller, request and actuator schema, with exactly equal laws for all permitted adaptive evaluation protocols and different deployment risk. The controller always dispatches each received item to bin 0 through a lawful action. The independently scored target is dispatch to the installed correct bin. In both completions the evaluation receiving-card registry designates bin 0. The same deployment context has an installed card designating bin 0 in one completion and bin 1 in the other. This off-evaluation installation fact is left free by the frozen source projection. At least one item must be dispatched on the declared deployment, yielding r(C)=0 versus 1. Admitting the independently read installed card makes the risk point-identifiable on this two-element class. The constructor claims no difference between fully specified identical complete contracts. Depends on T15's interaction semantics.

## T17 · Exact evaluation sufficiency

For any specified lawful protocol class, write L(C) for the collection of its full transcript laws. A target is a function of L on its attainable image if and only if it is constant on every nonempty fiber of L. A target-distinct equal-law pair obstructs exact recovery from this interface. This is a statement about exact law data, with no sample-size, estimator measurability, or computational claim. It uses the ordinary deterministic fiber criterion.

## T18 · Structural transport with audited common subprobability

Compare two finite source-connected implementations, a reference E and target D, over a common finite horizon T, for each declared paired context. Independently inspectable maps assign every reached concrete checkpoint a canonical anchor state z. The maps normalize physical lawful action choices to a common named interface, preserve the controller-visible observation and public stop behavior, and respect certified authority and any imposed whole-action resource freeze. The actual policy and its reference use the same observation-history law after these normalizations. Source-certified scoring maps trusted primitive outcome symbols to the same violation rule V on canonical trajectories. The event symbols and the anchor state are not additional controller data unless the tested interface exposes them.

For each implementation θ, reached checkpoint s over z, tick t and matched legal action a, its genuine conditional row has a normalized finite primitive vector ξ. A source trace check establishes that the next canonical state, public outcome and trusted event symbol together equal G_t(z,a,ξ), for a common, explicit deterministic map G_t. The true row and scoring must describe the run intended for inference, with state sufficient for conditional laws. The calibration of each normalized factor uses genuine, authorized measurements or source tables. A common certified lower factor ℓ_{t,j}(ξ_j | ξ_{<j},z,a) is bounded by each implementation's corresponding conditional probability at every concrete checkpoint over z on every prefix assigned positive lower weight. Check initials by a separately certified common lower pushforward m_0 on canonical initial letters. Factor lower bounds need not use independence among factors. They require coverage on every relevant reached row.

Let m_t(z,a;v) be the pushforward of the product of the lower factors by G_t to canonical next-letter v. Define μ on canonical length-T paths by m_0, the common controller rule on its public history, and the row subprobabilities m_t. With μ_i=μ(V=i), each implementation's violation risk is in [μ_1, 1−μ_0] and their risks differ by at most 1−μ_0−μ_1. If |m_0|≥1−η_0 and every reachable common row has |m_t(z,a)|≥1−η_{t+1}, the latter difference is at most 1−∏_{j=0}^T(1−η_j). Exact anchored initials and equal anchored conditional factor laws give μ_0+μ_1=1 and equality of canonical path laws. If every deployment context is paired with a reference context, the worst risks over the paired domain differ by at most the supremum of the pointwise mass deficits. The assumptions concern local typed transitions, authorization, correspondence, coverage and scoring. They do not take equality of target risks as an input. An experiment with a disturbed measurement interface needs a separate valid row or fidelity certificate. General transport to arbitrary contexts remains open.

## T19 · Risk intervals, endpoints and direct-measurement comparison

For nonempty attained risk image S={r(C):C∈H}⊆[0,1] in the sense that each element has a witness, let L=inf S and U=sup S, allowing endpoints themselves to be unattained. Uniform passing is equivalent to U≤ε. Uniform failing is equivalent to L>ε or L=ε and ε∉S. Otherwise the two threshold labels are both possible, with two completion witnesses. Finite S gives attained bounds. A sharp outer interval alone need not disclose holes or endpoint inclusion.

In an exact finite deterministic audit where one separately lawful, faithful and target-resolving direct measurement has constant cost d≥0, and all other permitted acquisitions are nonnegative-cost semantic queries, let W be the semantic-only minimum worst-case cost, using infinity for impossibility. The combined interface has optimum min(d,W) when the separate query is available on every reachable history including the root, and the other queries and target stay unchanged. This comparison concerns worst acquisition cost. It does not confer exactness on noisy, disturbing or partially supported readouts. A weaker finite-sample or incomplete direct comparator requires a common error, coverage and cost criterion.

## T20 · Uncovered-context mass

Suppose deployment d mixes a finite context alphabet with known weights, covered set S, conditional risk bounds [l_x,u_x] for x∈S and unknown risk in [0,1] elsewhere. The mixed risk is bounded below by Σ_{x∈S}w_d(x)l_x and above by Σ_{x∈S}w_d(x)u_x+w_d(Sᶜ). If endpoint vectors for all contexts are jointly attainable, both are sharp and their suprema over d give sharp worst-risk bounds. Pointwise endpoint attainability alone need not imply sharp worst-risk bounds. Totally unseen positive mass, with permitted completions that set its conditional risk freely and with matching evaluation laws, contributes its full weight to the identification gap. If a permitted deployment can concentrate on an unconstrained context, the worst risk may be 1 despite zero covered risk. There is no claim of sharpness under additional nonrectangular constraints.

## T21 · Transcript total-variation limit

For a target-distinct pair and any fixed feasible audit with transcript laws P and Q, the two wrong-decision probabilities of any forced binary discriminating rule satisfy α+β≥1−TV(P,Q), allowing postprocessing by shared randomness. If abstention is permitted, the same limitation holds when abstention counts as a failure on each hypothesis. With equal laws the forced or failure-counting maximum is at least 1/2. This is the ordinary two-hypothesis testing bound.

## T22 · Recorded stopped adaptive KL and reset allocation

Let the stopped transcript include predictable queries, responses, decisions to stop, and the common decision kernel or the auditor's independent coins. Protocols stop finitely almost surely under both compared completions P and Q. Every P-reachable response row used by the protocol is absolutely continuous with respect to its Q mate at the same recorded history and query, and the expected sum under P of absolute log response likelihood ratios up to stopping is finite. Then stopped-transcript KL equals the P-expectation of the sum over sampled rounds of history-conditional response KL. Any δ-correct procedure on the target-distinct pair, counting abstention as failure and with 0<δ<1/2, needs stopped KL at least kl(1−δ,δ). In the resettable independent-row case the sum equals Σ_q E_P[N_q] KL(P_q||Q_q). Expected audit cost for completion P is at least the optimum of the nonnegative count allocation minimizing Σ_q c(q)n_q subject to exceeding the same binary KL bound against each target-distinct competitor. This is a lower bound. It asserts no achievable static allocation, tightness for arbitrary models, or count-only substitution for history-dependent rows.

## T23 · Confidence-valid adaptive issuance

For any allowed adaptive protocol, let P_hyp be each candidate law for the prefix, with the protocol's own factors included. Fix a reference mixture M=Σ_c w_c P_c over a finite model class with positive weights. For 0<δ<1, retain candidate c at time t only if P_c assigns positive probability to the observed prefix and M(prefix)/P_c(prefix)<1/δ. The true candidate belongs to every such confidence set simultaneously with probability at least 1−δ, when actual data use that candidate law. At a stopping time, issue only from a nonempty target-homogeneous set, otherwise abstain. The probability of an incorrect issued certificate is at most δ, unconditionally. No finite certificate probability follows without separation. For resettable finite categorical queries where every opposite target pair differs in some legal outcome probability by at least Δ>0, a fixed schedule of n independent draws per query with n>2 log(2K/δ)/Δ², K the sum of the query alphabet sizes, produces a nonempty, homogeneous confidence set with probability at least 1−δ, by radius sqrt(log(2K/δ)/(2n)).

## T24 · Conditional-mean robust threshold auditing

Fix a nonempty finite candidate class, frozen finite globally repeatable legal probes Q, constant positive costs, and a target for each candidate. The evaluator may adaptively choose q and observes its binary trusted score Z and its own independent coins. All other observed fields, if any, are determined by these or have independently common law in the lower-bound construction. Under candidate c, at every legally reached history h after choosing q, a history-dependent nuisance responder may use any conditional law with mean in the certified closed interval I_cq⊆[0,1]. Assume the admissible nuisance class contains all stationary per-probe Bernoulli responses with means selected independently across probes from those intervals. The sufficient direction only requires the conditional mean bounds and does not require this richness.

For δ∈(0,1/2), there is a finite-cost audit with uniform probability of wrong decision or abstention at most δ if and only if every target-distinct pair has disjoint intervals for some legal q. The necessity uses a target-distinct pair with common per-probe laws. For sufficiency, on the nth acquired score from q use
$
b(n)=\sqrt{\log(2|Q|\,n(n+1)/\delta)/(2n)}.
$
Retain a candidate only while all its previous sampled mean distances from its corresponding intervals have been ≤b(n). For each probe that separates some target-distinct pair, let g_q be the minimum strictly positive gap among disjoint opposite-target interval pairs and choose a finite n_q with 2b(n_q)<g_q. When the set still has differing targets, choose a separating q for one such pair and acquire up to n_q total draws of q. Stop at a nonempty homogeneous set or abstain on emptiness. This rule eventually stops and has worst total cost at most Σ_q c(q)n_q over separating probes. If all targets agree initially, cost is zero. One sufficient source-verifiable way to obtain interval anchors is an independently implemented honest score V whose conditional mean stays in [a_cq,b_cq], plus a separate trusted coupling condition Pr(Z≠V | h,q)≤η_cq. The interval [a_cq−η_cq,b_cq+η_cq] clipped to [0,1] is then valid even when nuisance behavior and the corruption event depend on history and score. No new deployment guarantee follows from a probe margin unless the target class is itself independently justified. The proof must preserve possible non-resetting history. Dependencies are T15/T21 for the obstruction and elementary bounded-score concentration for the positive result. Global minimal cost and arbitrary changing probe availability are outside the claim.
