# Scope clarifications after the proof-blind seal

The original statement-only seal is retained at `37da12f631eb2aa18e21d733cc1f2134d14e45c9`. These clarifications give the exact scope used by the constructor proof. A fresh verifier can inspect the unaltered seal and record its own objections before using this document.

- T18 reads the common admitted observation-policy law as a conditional kernel given the complete physical prefix, evaluated at the admitted component. Retained randomized controller memory must be represented by its sufficiently augmented allowed observation/controller state or matched seed and update. Equality of marginal one-step actions after silently dropping memory is weaker.
- T22 accounts for all model-dependent information. A distinguishing initialization must appear as its own conditional response in the total KL. The reset allocation expression with only acquired probe counts presumes no separate initial information, or explicit conditioning on genuinely common registration data. For a simple missing term counterexample, an externally recorded initial flag with different Bernoulli means and an immediate stop gives positive KL and zero sampled-probe sum.
- T23 constructs the full set satisfying the likelihood-ratio and support tests or their nested intersections. Arbitrarily dropping candidates that pass those tests is not covered.
- T24 uses the full nested set of interval-eligible candidates and allows early termination from a homogeneous or empty set. Its lower bound additionally depends on which fields are jointly observable and the stated rectangular Bernoulli richness. Its positive result requires only the certified uniform conditional means.

These scope points do not reverse any accepted experimental observation.
