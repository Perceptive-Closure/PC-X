# Primary literature and novelty boundaries

This is a constructor literature audit. Formally distinct changes in known object classes are candidate adaptations even when their proof is complete. The project-specific operational embeddings need separate novelty review before making an originality claim.

| Primary source | Mathematical overlap | Boundary for this construction |
| --- | --- | --- |
| Skowron and Rauszer (1992), [The Discernibility Matrices and Functions in Information Systems](https://link.springer.com/chapter/10.1007/978-94-015-7975-9_21) | Differences between discernible rows generate minimal attribute sets. | T04–T06 use an externally specified target quotient and fixed probe prices. Algebraic characterization alone is established attribute-reduction logic. |
| Golovin, Krause and Ray (2010), [Near-Optimal Bayesian Active Learning with Noisy Observations](https://papers.neurips.cc/paper/2010/hash/1e6e0a04d20f50967c64dac2d639a577-Abstract.html) | Equivalence-class determination distinguishes edges between different classes by test outcomes. EC² addresses adaptive Bayesian acquisition. | Target fibers here are a disjoint partition with known fixed semantic readouts. T06 and T08 are exact uniform/realized and worst-case objectives, without a prior or generic noise approximation claim. The normative readout premise must come from the contract. |
| Javdani et al. (2014), [Near Optimal Bayesian Active Learning for Decision Making](https://proceedings.mlr.press/v33/javdani14.html) | Decision-region determination stops when compatible hypotheses lie in a common decision region. It allows overlapping regions. | Ordinary T04 has one target label per compatible completion, a special partition. T07's rooted E/R/A example establishes another governed target that changes on ignored facts. It does not create decision-region determination. |
| Jain, Klauck and Santha (2010), [Optimal direct sum results for deterministic and randomized decision tree complexity](https://arxiv.org/abs/1004.0105) | Exact direct sum for independent query tasks, among broader relation statements. | T08's static/adaptive/realized formula is the weighted deterministic local-read adaptation, with a short component-value adversary. Shared readouts, dependent evidence and a scalar threshold over combined costs require different mathematics. |
| Hyafil and Rivest (1976), [Constructing Optimal Binary Decision Trees Is NP-Complete](https://people.csail.mit.edu/rivest/pubs/HR76.pdf) | Optimal expected external path length in object identification is NP-complete. | This does not directly prove the static minimum T10.a or the serial paired decision T10.b. Those reductions are independent and explicit. The bitwise address function and generic cost hierarchy are known query-model mechanisms, while T09 supplies a declared PC realization. |
| Karp (1972), [Reducibility Among Combinatorial Problems](https://doi.org/10.1007/978-1-4684-2001-2_9) | Exact Cover, Node Cover and Knapsack provide classic NP-complete starting problems. | The T10.a incidence-table argument is standard hitting-set hardness. The additional work is the small E/R freeze embedding and one residual binary stage that makes agreement-conditioned crossing exactly an integer subset sum. An unconditional novelty claim is unsupported. |
| Chvátal (1979), [A Greedy Heuristic for the Set-Covering Problem](https://doi.org/10.1287/moor.4.3.233) | The weighted set-cover greedy bound applies with a logarithmic dependence on the largest set size. | For a finite explicitly generated feasible edge list, a query covers those edges it intersects. This gives the classical harmonic approximation as an optional explicit-edge upper bound, not a solution to symbolic pair generation or a certificate of optimality. |
| Chatterjee, Doyen, Henzinger and Raskin (2007), [Algorithms for Omega-Regular Games with Imperfect Information](https://lmcs.episciences.org/1094) | Observation-based control, knowledge state construction and fixed-point antichains. | The PC calculations use finite proper worst-support closing trees and resource-specific deletion of source atoms. Least-depth cycle exclusion and support union apply under stationarity as stated. The method of using belief states itself is prior. |
| Edmonds and Fulkerson (1970), [Bottleneck Extrema](https://doi.org/10.1016/S0021-9800(70)80083-7) | Clutters have a blocker given by their minimal transversals. | The involution in T12 is classical. The modeling step deriving policy occurrence supports and retaining all branches of the atomic intervention is PC-specific scope, not new combinatorial duality. |
| Jha, Sheyner and Wing (2002), [Two Formal Analyses of Attack Graphs](https://www.cs.cmu.edu/~wing/publications/Jha-Wing02.pdf) | Defensive preventative-measure optimization via hitting sets on paths. | T12's edge is the full support of one observation-measurable *contingent* closing policy, not an individual path in a fully specified reachability graph. The distinction is required for correctness. No operational attack is constructed. |
| Chandrasekaran, Karp, Moreno-Centeno and Vempala (2011), [Algorithms for Implicit Hitting Set Problems](https://epubs.siam.org/doi/10.1137/1.9781611973082.48) | Optimize over an implicit set system using a witness for violated edge coverage. | T14.a is the exact verification-driven specialization. T14.b derives the separation oracle from serial resource structure and its readouts. X05 already computes and checks that restricted factorization. Its mathematical reconstruction is retrospective. |
| Dechter (1999), [Bucket Elimination](https://doi.org/10.1016/S0004-3702(99)00059-4) | Exact constraint elimination with exponent controlled by interaction width. | T14.c supplies one explicit paired finite-score DP and budget complexity bound for governed modalities compiled to stage-local scores. The general width technique is prior, and small width requires modeling evidence. |

T11's image-set principle and value monotonicity use D-35 Proposition 3 and charter pp. 13–14. The exact joint envelope includes correlations that the manuscript's primitive rectangular approximation does not express. Computable image attainment over masks and complete canonical examples are adaptations of finite model enumeration with explicit semantic guards. T13's witness/refutation procedure is similarly constructive finite reasoning. It retains a precise failure for unbounded pointwise computability.

Pending novelty review should investigate previously published same-root authorization/representation separations, precise worst-case readout constraints in resource-aware verification, and elimination of paired crossing conditions with additional monotone structure. The product-edge proof and correlated paired DP have exact restricted statements. Novelty conclusions beyond the reviewed sources remain unresolved.
