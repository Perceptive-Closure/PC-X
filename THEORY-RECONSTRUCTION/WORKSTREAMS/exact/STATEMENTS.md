# T04–T14 statement packet

Constructor candidate statements for proof-blind review. Charter pp. 7–17 are the source for identifiers. Subclaims retain the original scope while making restricted extensions explicit. References to another claim declare dependencies. Every type and assumption used below is part of the statement.

## Shared models

**Finite semantic table.** A nonempty finite set $\mathcal C$ contains the source-compatible complete contracts, with equalities and any quotient by a declared source-preserving semantic equivalence accounted for before forming the table. A target $f:\mathcal C\to Y$ is invariant under that quotient. An authenticated deterministic read-only menu $Q=(q_1,\ldots,q_m)$ consists of total maps $q_j:\mathcal C\to V_j$ and fixed known positive costs $w_j$. Asking a query neither changes the contract, available queries, other costs, nor target. In formulas $B\subseteq\mathcal C$ is a posterior information cell, $y_J(x)=(q_j(x))_{j\in J}$ for $J\subseteq[m]$, $D(x,x')=\{j:q_j(x)\ne q_j(x')\}$, and empty compatible evidence has separate verdict INCONSISTENT. Structural infeasibility has value $+\infty$. Finite input complexity claims use explicit finite domains and binary-encoded integers unless otherwise stated.

**Resource kernel.** A finite nonempty state set $S$ has $\omega:S\to O$, a closed subset $G$, atomic enabled actions $A(s)$ from a finite set $A$, and nonnegative deterministic cost $c(a)$ known before acting. For every enabled $(s,a)$ its nonempty finite support is a set of labeled successor pairs $(u,s')$ with outcome $u$ visible. Checkpoints are reached from a fixed nonempty observation-homogeneous belief $B_0$. Policies select actions from visible observations and outcomes alone, enabled at all states in the current belief. Observing $(u,\omega(s'))$ updates the belief by union of all supporting successors with that same visible label. Stop is allowed when all compatible states lie in $G$. A proper closer is a finite such tree with all reached leaves closed. Its cost is the maximum branch sum of $c$; a missing proper closer has value $+\infty$. A mask $M$ removes entire atomic occurrences $(s,a)$, preserving all other supports, costs, information, initial belief and closure status. The kernel value after that deletion is $\kappa(M)$.

A **canonical PC realization** additionally supplies a finite history set, finite latent worlds with two sealed decision labels, a nonempty compatible world fiber under the current history and equivalence relation on histories, and a distinguishable normalized history $H(s)$, equivalence relation $P_R(s)$, and extensional authority $\Lambda(s)$. $G$ consists of states whose represented compatible world fiber has one label. At $(s,a)$, a resource belongs to the touch set if its coordinate changes on any positive-support successor. An $F\subseteq\{E,R,A\}$ freeze masks precisely those occurrences whose touch intersects $F$. Fixed ordinary preconditions and interfaces determine source candidates and authority governs whether they are allowed. Declared queries read source-located metadata about admission, representation, or route selection independently of measured target execution.

**Serial threshold model.** $n$ stage-mode sets $Z_i$ are finite. In the product case the completion set is $\prod_i Z_i$, with nonempty factors. A mode $z_i$ has an already derived local nonnegative integer cost $v_i(z_i)$, possibly $+\infty$. A nonnegative integer terminal cost $\tau$, possibly $+\infty$, is fixed across assignments. For integer $b\ge0$, $f(z)=1\{\tau+\sum_i v_i(z_i)\le b\}$ uses extended-real addition. The queries and their fixed positive prices partition into stage-local menus $Q_i$ with answers depending only on $z_i$. A resource-kernel instance supplies this score when stages execute sequentially, every valid path progresses through a common interface and known entry belief for the next stage, internal states are open, there is no bypass or hidden cross-stage parameter or carried resource affecting later capabilities, and the fixed goal suffix begins only after the last common exit. Stage observations may reveal local facts, with no effect on later admissibility or support. Costs add, and between-stage composition retains all positive-support branches.

## T04 · Exact disagreement characterization

For each nonempty posterior $B$, a query set $J$ determines $f$ on $B$ exactly when $J\cap D(x,x')\ne\varnothing$ for every $x,x'\in B$ with $f(x)\ne f(x')$. In this case a unique decoder exists on $y_J(B)$. Fixed-target valid evidence refinement contracts the identified set $f(B)$.

## T05 · Audit-interface impossibility

In the finite semantic table, a uniform static or proper adaptive audit determining the target exists exactly when no target-distinct pair has $D=\varnothing$. Such a pair defeats arbitrary repetition and zero-error randomization using the frozen interface. There is no positive identification on an inconsistent evidence set.

## T06 · Uniform and realized certificates

Taking the minimum total price over T04 transversals gives the uniform static optimum $S_f(B)$. For $x\in B$, its minimum realized cost $L_f(x;B)$ is the minimum total price of a set hitting $D(x,x')$ for each $x'\in B$ with $f(x)\ne f(x')$. A minimum over an infeasible family is $+\infty$. The two minima differ in general, even with unit costs and finite optima.

## T07 · Target versus full identification

For identity $I$ on the declared semantic quotient, $S_f(\mathcal C)\le S_I(\mathcal C)$. For every $m\ge1$ there is a finite fully observed canonical PC family of $2^{m+1}$ contracts with a common source entry and unit-price local semantic probes such that the budget-one $R$-frozen closure target has $S_f=1$ while $S_I=m+1$. Holding the other coordinates fixed, changing any of the $m$ non-primary review facts changes the $A$-frozen value at that same entry. If any one review probe is unavailable, $S_I=+\infty$ and $S_f$ remains 1.

## T08 · Exact adaptive minimax and product identification

For finite nonempty $B$, the proper worst-case adaptive cost $V(B)$ is zero if $|f(B)|=1$. Otherwise it equals
$
\min_{j\text{ splits }B}\left(w_j+\max_{a:q_j^{-1}(a)\cap B\ne\varnothing}V(q_j^{-1}(a)\cap B)\right),
$
with $+\infty$ when no split exists. Finite optima have deterministic decision trees. This minimax objective is the supremum over all supported randomization branches if randomized policies are admitted. If independent factors have disjoint local query menus and the target is the whole tuple of their factor targets, the uniform static and adaptive optima add across factors, and the realized optimum adds at the specified tuple.

## T09 · Hierarchy and routed separation

For the finite table, $\max_x L_f(x;\mathcal C)\le V(\mathcal C)\le S_f(\mathcal C)$, and both inequalities can hold strictly in a single instance. For each integer $r\ge0$ there is a finite canonical PC family with one selected route encoded by $r$ configuration bits and $2^r$ independent gate facts. The audit menu reads precisely those bits at unit cost. A legitimate route-specific budget-one $R$-freeze threshold has static optimum $r+2^r$ and adaptive worst-case optimum $r+1$.

## T10 · Complexity and its representation boundary

**T10.a.** In the explicitly listed table, the decision $S_f\le k$ is NP-complete even for Boolean target, Boolean unit-price queries and finite nonempty domains. The hardness holds for explicit families of fully observed canonical PC contracts whose common source entry has only cost-one one-step closing routes, with an $R$-freeze budget-one target and independently read admission facts. The list of eligible semantic assignments is part of the representation.

**T10.b.** In the serial threshold model with two modes per stage, stage-local probes and binary-encoded $b,v_i$, deciding whether there exists a target-distinct pair agreeing on all selected probes is NP-complete. The hardness remains for fully observed serial canonical PC kernels with deterministic acyclic local support, matched entry and exit profiles, $R$-freezing, and a fixed pure-E goal suffix. Each nonterminal stage contributes one of two nonnegative integer local values. Consequently a polynomial-in-budget exact bound need not be polynomial in the bit length of the input. The T14 algorithms below give structural tractability with bounded local widths and suitably bounded numeric budget.

## T11 · Exact correlated freeze envelopes

For a fixed resource kernel and arbitrary nonempty family of compatible mask profiles $M_F(C)$, for each $F$ the exact identified cost set is $\{\kappa(M_F(C)): C\in\mathcal C\}$. When masks are the only varying objects, the set is finite even if the evidence descriptions are infinite, and the attainable lower and upper endpoints lie between the values at the intersection and union of compatible masks. Attainment of either extreme input mask suffices for attaining the corresponding bound and is unnecessary for value-level equality. Correlation can make these bounds strict. Joint signatures are the costs of a *single* compatible mask profile for all freeze coordinates, so multiplying separately sharp coordinate sets can add impossible signatures. Each $\kappa$ admits the finite belief-horizon calculation with at most $2^{|S|}-1$ action levels when finite. If admissible mask profiles are effectively decidable, a finite exact procedure returns the joint set and a witnessing profile for each value. If kernel costs can vary without a finite discrete representation, an infimum or supremum need not be attained.

## T12 · Closure support versus intervention blockers

In the fixed resource kernel, for finite budget $b$, let $H_b$ be the inclusion-minimal supports of proper closers of worst cost at most $b$. A support is the set of $(s,a)$ used on some positive-support branch. Whole-action deletion $M$ leaves a budget-feasible closer exactly when some $U\in H_b$ is disjoint from $M$. The minimal destructive masks are the inclusion-minimal transversals of $H_b$, and dualizing that clutter returns $H_b$. The family may be generated exactly by combining supported outcome-belief continuations, retaining only inclusion-minimal sets, to horizon $2^{|S|}-1$. Intermediate or output antichains may be exponential. Empty supports and empty families are interpreted separately. This result preserves the original positive-support structure.

## T13 · Constructive ambiguity or certificate

For a finite well-formed symbolic contract class, assume a verified feasibility checker, exact target and query evaluation, and a terminating proof-producing oracle for target-distinct compatible pairs subject to a list of equal-query constraints. A verified feasibility witness followed by testing the empty constraint set and, when needed, the full query set suffices to produce exactly one terminal conclusion: IDENTIFIED with a value and no-conflict proof, UNDERIDENTIFIED with a compatible opposite-target witness when full-menu collisions are excluded, AUDIT-INACCESSIBLE with a target-distinct whole-interface collision, or INCONSISTENT with an emptiness proof. Incomplete or unverifiable required calls with no decisive verified conclusion return UNKNOWN. An independently verified target-distinct pair can certify the narrower nonidentification statement even while accessibility is unresolved. Pointwise decidability alone does not suffice for quantified feasibility over an unbounded class.

## T14 · Exact implicit synthesis and structural extensions

**T14.a.** With the assumptions of T13 and exact weighted-transversal optimization on the collected edges, the minimum uniform certificate is obtained by repeatedly solving the current lower-bound transversal problem and adding an independently checked unhit disagreement edge. A certified no-conflict candidate attains the optimum. An empty edge certifies inaccessibility. At most $2^{m}-1$ nonempty additions are possible. An exhausted or unverified search with no conclusive result does not certify identification or optimality.

**T14.b.** In the serial product model, a selected set misses a global target-distinct pair exactly when it misses the edge of a pair differing at one stage. At stage $i$, the pair $z_i,z'_i$ contributes its local disagreement edge exactly if some sum of one cost from every other stage plus $\tau$ makes one total at most $b$ and the other greater than $b$. Thus the optimum is the sum of local minimization costs under these attainable-context edge families. The minimum full-identity audit is the analogous stagewise minimum over all distinct local semantic modes and can equal the minimum target audit. A finite local table and binary integer costs admit a budget-capped pseudo-polynomial edge construction plus exact $2^{|Q_i|}$-subset local optimization. The paired oracle can alternatively use extremal costs within local equal-answer cells, coordinatewise capped sums and Pareto dominance favoring low left cost and high right cost, and recover a true single-stage witness. Cross-stage evidence restrictions, coupled local queries, or stateful transport across stages need separate justification.

**T14.c.** For a correlated finite class given by extensional constraint tables, additive nonnegative integer local scores, and local query equality, take the product of two modes at each stage. Given a nice tree decomposition of width $w$ with $N$ nodes and a bag containing the scope of each factor, paired target-distinct, same-query feasibility is decidable without materializing the completion catalog. If each local mode domain has size at most $d$, the DP uses up to $d^{2(w+1)}(b+2)^2$ Boolean states per bag and $O(N d^{2(w+1)}(b+2)^4)$ table updates apart from local factor-read and bit-arithmetic costs. A true state gives a compatible pair. At fixed width and suitably bounded numeric budget this is tractable in the tabulated input. The outer weighted optimization need not be tractable.
