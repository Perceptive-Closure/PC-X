## Shared finite model

A contract has finite latent worlds $X$ and checkpoints $S$, a fixed entry $s_0$, normalized history representatives $U$, a compatibility relation \sim\subseteq X\times U$, an admitted-history representative $H:S\to U$, a certificate equivalence relation $P(s)$ on $U$ at each state, an extensional authority operator $\Lambda(s)$, and a controller observation $\omega(s)$. The sealed target is $a:X\to D$. The represented fiber is $C(s)=\{x:\exists h\in [H(s)]_{P(s)}\ (x\sim h)\}$. Every reachable fiber is nonempty. A checkpoint is closed when $a$ is constant on $C(s)$. A representative $H(s)$ need only name its equivalence cell. A compatible history in that cell may differ from the representative.

Let $Q(s)$ be the enabled set of declared source-atomic actions at $s$. Source availability, ordinary preconditions, and $\Lambda(s)$ determine this set. A change specific to authority-admissibility with the other inputs fixed changes $\Lambda$. For each $q\in Q(s)$ the nonempty positive-support successor set is $N(s,q)\subseteq S$. Each such edge $(s,q,u)$ has a visible outcome $y(s,q,u)$. Costs $c(q)$ are real, finite and nonnegative. The interface fixes the source partition of actions and checkpoint locators. The touch $T_s(q)$ is the union over all $u\in N(s,q)$ of the coordinates $E,R,A$ whose values in $(H,P,\Lambda)$ differ extensionally between $s$ and $u$. A freeze $F\subseteq\{E,R,A\}$ removes the full actions whose touch intersects $F$.

Observation histories start with $\omega(s_0)$ and append the selected action, visible outcome and next observation on each step. A deterministic proper policy uses observable histories, acts only with actions enabled and surviving the freeze at every consistent state, has a finite tree of reachable observable histories, and stops only when all physical leaves are closed. The cost is the maximum accumulated cost over positive-support leaves. Equivalently one can restrict to currently observation-dependent policies wherever explicitly stated. Every strengthened claim using finite memories or unrestricted history-dependent policies specifies which convention it needs. Define $k_F(s_0)$ as the infimum of such costs or $+\infty$ for absence of proper policies. The eight coordinates use $(\varnothing,E,R,A,ER,EA,RA,ERA)$. When $k_{\varnothing}<\infty$, the R penalty is $\Delta_R=k_{\{R\}}-k_{\varnothing}$. It is undefined for an unclosable baseline.

Source evidence $\Omega$ specifies a nonempty class $\mathcal C(\Omega)$ of complete contracts with a common referenced entry locator and any other fixed source locators. This class may leave semantic fields or action boundaries unspecified. The identified set consists of all eight-coordinate values at those realized entry locators. Definite or possible touch compares actions only where a common locator is fixed. Controller equivalence uses the full unrestricted positive-support trees for all policies, including observations, actions, outcomes, cost, terminal labels and stopping behavior. It does not include hidden extensional touch.

## T01 · D-35 Theorem 1

For each real $g>0$, two finite controller-equivalent contracts have unrestricted cost $1$ and frozen-R costs $1+g$ and $1$. A second pair has the same unrestricted value and equivalence with frozen-R costs $+\infty$ and $1$. This is an existential statement about the declared finite PC class with the declared observable channel.

## T02 · D-35 Theorem 2 and Corollary 1

For each real $g>0$, one partial source evidence description has two finite complete realizations. They agree on raw implementation data flow, source graph and action locators, observed interaction, costs and visible terminal target classes. They have unrestricted value $1$ and opposite pure touch types $E$ and $R$ for the same fast transition. Their frozen-R values are respectively $1$ and $1+g$. Another such description realizes $1$ and $+\infty$. Correct evaluation given each complete realization need not identify its counterfactual from the partial source description.

## T03 · D-35 Theorem 3

1. Fixing $H,P,\Lambda$ extensionally and the source-exposed atomic successor relation determines touch at every declared action locator.
2. Let $B\subseteq S\times S'$ relate entries. Each related pair has equal observations, equal open/closed status and equal labels where closed. For each observation $o$ there is a common action renaming $\alpha_o$ that maps the enabled menu of each related $s$ bijectively to that of its mate. For each $(o,q)$ a common outcome renaming $\beta_{o,q}$ is a bijection on the declared outcome classes for that interface, restricted to the positive support of each related state. Costs and touches are preserved by $\alpha_o$. For each positive successor on either side there is a related successor with the matched outcome on the other side. Under every freeze, both contracts have the same proper-policy costs, hence the same signature and finite-baseline R-penalty classifications. Action and outcome renamings are independent of hidden physical state. No all-pairs successor relation is assumed.
3. If all admissible completions belong to one class of this interface-equivalence at the entry, their signature set is a singleton. The statement is sufficient and relative to the declared interface.

## Auxiliary closure algorithm statements

For a given freeze and nonempty information set $B_s\subseteq S$, the available actions are precisely the intersection of its members' surviving menus. Each possible outcome/next-observation pair induces the information set of supported successors matching both signals. Stop is legal exactly at an information set consisting entirely of closed checkpoints. The Boolean sure-closing family is the least fixed point of adjoining information sets with an admissible action all of whose possible successor information sets already win.

Under finite nonnegative costs, a proper optimum admits a tree with no repeated information set on any root-to-leaf path and is attained. For each information set the minimal cost among trees of height at most $j$ obeys the truncated min–max recursion with stopping cost zero, nonterminal base cost $+\infty$, and no admissible action also giving $+\infty$. Iterating the finite belief recursion up to the number of nonempty state subsets returns exact values. The height iteration descends from infinity on open beliefs. A low algebraic Bellman fixed point, by itself, does not witness proper closure.
