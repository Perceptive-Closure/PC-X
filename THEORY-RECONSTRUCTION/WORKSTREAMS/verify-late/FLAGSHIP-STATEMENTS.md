# T30 statement-only seal · serial governed deadline fragment

## Exact problem

Let n ≥ 1, common predeclared entry observations i=1,…,n, and terminal observation done. In each stage i, the finite set D_i of semantic modes is explicitly nonempty. A complete contract is one tuple m in the full Cartesian product of the D_i. The only uncertainty-reducing external operations are a frozen finite family of read-only deterministic queries Q_i about mode i, with fixed positive rational costs independent of order and answers. No such query mutates the system, task, deadline or modes. They are lawful source readbacks whose provenance is a premise, not inferred from an eventual target verdict. An actual answer cell restricts each D_i to a subset, with inconsistency exactly when some subset is empty.

For each stage i fix positive integer base tariff a_i, extra tariff w_i>0, lawful service target job_i and a bit x_i:D_i→{0,1}. Before freezing R, the canonical finite reference exposes exactly two atomic processing modes fast_i and slow_i from every hidden checkpoint represented as stage i. A fast action costs a_i, and its complete positive support contains some successor changing the declared extensional certificate relation if and only if x_i(m_i)=1. A slow action costs a_i+w_i and preserves the relation on every successor. Both actions are baseline lawful under the fixed authority and complete the designated job, proceeding only to the next mandatory stage or done. There is no lawful action making useful progress that skips a stage. Silence or refusal fails full service. Freeze R removes the whole fast action when the bit is 1. No additional observation of the local mode is available before the stage action, except prior legitimate external audit answers. Any logged differences in earlier stages leave the full current-stage residual modes possible whenever consistent with the earlier history. The complete checkpoint support is composed by lawful successive steps under the declared reset boundary.

A deployment instance may have further hidden checkpoints. The independently checked anchor is an explicit map from its reachable checkpoints to these stages and from the declared public interface to the atomic action classes. The starting projection is 1. At every relevant concrete checkpoint, the projected stage, enabled action classes after R freeze, extensional resource effects governing that freeze, action tariffs and completed-job predicates match the appropriate declared rows. Every concrete supported transition projects to an allowed next-stage edge with the declared job event, and required actions and nonempty support exist at every such checkpoint. Additional operational actions, shortcuts, target-changing bypasses and hidden event relabeling are excluded by this local correspondence. This is a condition on independently checked interface facts, before classifying a deadline.

Use target Ψ(m)=1 if the lawful procedure can serve all jobs in deadline B (a nonnegative integer) on every supported R-frozen path at completion m. An implementable policy acts only from authorized observations and acquired answers. Costs of the external audit and of completing the work are separate.

## Candidate claim T30.S

1. For each completion the exact optimum is v(m)=Σ_i (a_i+w_i x_i(m_i)) in both canonical and anchored deployed models. On a nonempty Cartesian answer cell U, the minimum worst-supported cost of one lawful all-jobs policy working across the entire cell is max_U v. The policy is observable and executable from the cell without knowing m. For finite stochastic realizations of the same supported paths this is equivalently a zero-risk guarantee for the deadline and job predicate under the declared support family.
2. Let L and H be min_U v and max_U v, attained by mode tuples. Nonempty target result is {1} if H≤B, {0} if L>B, and {0,1} otherwise. Ambiguity has explicit compatible tuples. Every positive result has a shared lawful full-service policy. Empty evidence is inconsistent.
3. For fixed U and each stage i, define the local crossing pairs to be two stage-i modes whose costs can induce opposite deadline verdicts with identical actual compatible choices at every other stage. A static query set identifies Ψ uniformly exactly when its selected stage-i queries separate every local crossing pair for every i. Weighted global static minimum is the sum of exact local minimum hitting costs. An empty query-disagreement edge supplies a pair that no audit over the deterministic menu can distinguish, even adaptively. Otherwise an exact optimal static acquisition strategy is constructed. No minimizing claim for arbitrary adaptive or stochastic-cost audits is made.
4. The procedure can compute attainable outside-stage sums up to the residual budget using capped additive dynamic programs with completion witnesses. It enumerates local modes and local query subsets only. With maximum local menu size q, maximum local mode count d, and excess budget b=max(0,B−Σ a_i), it uses O(n² d (b+2) + n d²(q+1)(b+2) + n 2^q d²(q+1)) unit operations by a direct implementation with backpointers. It does not enumerate the product of semantic completions. Integer arithmetic is on values capped at b+1 except to validate input, reconstruct exact witnesses or compute extrema. For bounded d,q and polynomially bounded numeric b this gives a polynomial structural algorithm. The bound is pseudo-polynomial in general.
5. In an n ancillary-stage example plus one gateway, every base tariff is 1, ancillary slow increments are 1, the gateway increment is n+1, and B=2n+1. Each independent bit is a genuine cross-variant R-freeze fast-service difference with a unit-cost local readback. The units of optimal static target and full-mode identification are respectively 1 and n+1, and the positive cell admits a single lawful all-jobs policy. This shows target-specific oversight in a finite governed setting. The general charter's stronger exponential or strategic result remains an open question.

The proof should address soundness, constructiveness, completeness, interface-relative exactness, exact static audit optimality, transport from the stated anchors, useful work and computational advantage in this same fragment.
