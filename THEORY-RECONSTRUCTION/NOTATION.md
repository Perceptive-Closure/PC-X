# Notation

| Symbol | Meaning |
| --- | --- |
| $x\sim h$ | Latent world $x$ is compatible with history representative $h$. |
| $H,P_R,\Lambda,\omega$ | Admitted history, certificate equality, authority and controller observation. |
| $Y,\mathrm{Succ}^+$ | Visible transition outcome and full positive successor support. |
| $T_s(q),F$ | Extensional source-atomic resource mask and frozen resource set. |
| $C_R(s)$ | World image of the current certificate cell under compatibility. |
| $K_{\Pi,C}$ | Signature in order empty, E, R, A, ER, EA, RA, ERA. |
| $B,U$ | Belief or residual compatible cell. A budget is labeled separately where used. |
| $C_\Omega,\mathcal I_\Psi(\Omega)$ | Nonempty-or-inconsistent compatibility set and its exact target image. |
| $\Gamma,\gamma_q,D(C,C')$ | Selected pure readbacks, a typed query response and their full disagreement edge for the pair. |
| $L_\Psi,A_\Psi,S_\Psi$ | Realized, worst-case optimal adaptive and uniform static acquisition minima. |
| $P_C^e$ | Law of the full visible transcript when evaluation protocol $e$ is used at $C$. |
| $V,M,\Psi$ | Actual violation bit, monitor alarm bit and specified target property. |
| $r(C,d),r(C),\varepsilon$ | Context risk, its deployment supremum and the allowed threshold. |
| $m_t,\mu,\mu_0,\mu_1$ | In T18, dominated conditional row, trajectory submeasure, and its safe and violating masses. |
| $\delta,\alpha$ | In inference sections, certification error bound or calibration confidence error as specified. |
| $G,L_i,e,d_i$ | In T27, actual global and local violation events, uncovered containment mass and local retention allowance. |
| $Q_i,a_i,w_i,x_i,B$ | In T30.S, local external readbacks, operational base/extra tariffs, R-touch mode and deadline. |
| $+\infty$ | Structural impossibility for a proved complete model, never a timeout or missing assessment. |

The symbol $q$ can denote an in-task atomic operation or an external query when unambiguous in its local theorem. Price scales for those two uses are independent. A minimum includes its attainability conditions. A risk infimum or supremum need not be attained. An opposite-target inequality uses the exact threshold convention near equality.
