## Extraction witnesses

Use worlds $0,1$ with differing targets, a common representative $u$ compatible with both, and $r_i$ compatible with world $i$. For each following pair take a fixed one-atom graph with an open entry and open successor and genuinely positive support. Use the same action and logs. Ordinary preconditions allow the atom only at entry.

- **H omitted.** Use the universal certificate partition. Compare a successor $H=r_0$ with $H=u$ in two otherwise identical transitions with root $H=u$. Both fibers remain open because the certificate class is universal. The touch is $\{E\}$ versus the empty set.
- **P omitted.** Hold $H=u$ throughout. In one version merge $r_0,r_1$ after the action. In the other retain the identity partition. The represented $u$ cell has both targets in each, while the extensional partition changes only in the first. The touch is $\{R\}$ versus the empty set.
- **Authority omitted.** Use the same $H,P$ throughout. Provide a declared reserve interface whose ordinary precondition is false on these checkpoints. Change the authority operator's answer for the reserve interface on the first successor only. Keep the authority for the executed atom fixed and all other declared conditions identical. Its ordinary availability and enabled support graph are unchanged. The touch is $\{A\}$ versus the empty set, consistently with extensional authority coherence.
