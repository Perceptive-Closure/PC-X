# P5 · Exact non-R barrier

D-35 p. 7 and Appendix G pp. 14–15. **Constructor verdict:** the state attractor is exact under policy sufficiency. Exact observable-history synthesis in its absence uses information sets.

Use the same observations, action identities and canonical touch as the underlying finite contract. Policy sufficiency means any two equally observed checkpoints have the same open/closed status, menus and touch, and each common action has the same set of successor observations. Let $W_0$ be closed states. Define $W_{t+1}$ to be $W_t$ together with any state having a non-R action all of whose successors are in $W_t$.

The layers are observation-class unions. This holds at $W_0$ by terminal status compatibility. Suppose it holds at $W_t$. The same witness action from any state newly added has the same name and non-R eligibility throughout its observation class. Its successor-observation set lies entirely in classes already in $W_t$. The entire observation class therefore enters $W_{t+1}$. At each winning open observation select an action witnessing its earliest layer. Every step in the resulting policy strictly lowers rank, so all leaves close in finitely many steps and only non-R atoms are used.

Finiteness gives a fixed point $W$. For $s\notin W$, every surviving action has a positive successor outside $W$. A legal finite tree from such an $s$ has a branch that keeps choosing those successors until it stops or lacks an allowable action. Its endpoint is outside $W_0$, so the tree fails sure closure. This proves the exact barrier claim.

**No-sufficiency counterexample.** In P1's arena with aliased $u_0,u_1$ and equal incoming outcomes, both states have a correct non-R repair of their own and both appear in the statewise winning layer. They need opposite actions while observationally indistinguishable. No common choice leads surely to closure, though every statewise restriction is solvable. The belief attractor from the root in the corresponding full transition model rejects this hidden pair. [Information-set proof](../WORKSTREAMS/foundation/MODEL-AND-ALGORITHM.md) · [P1](P01.md)

Outcomes distinct from observations may reveal more information in other systems. The sufficiency argument already achieves a rank-decreasing policy using current observations and needs no extra richness in outcomes. The exact belief transition retains both signals whenever available.
