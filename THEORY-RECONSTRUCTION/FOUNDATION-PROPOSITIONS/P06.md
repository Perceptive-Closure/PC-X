# P6 · Strict evidence/representation complementarity

D-35 p. 7 and Appendix G p. 15. **Constructor verdict:** a typed finite construction gives the $2d$ optimum and both structural restrictions.

Fix $d\ge1$. Use worlds $X=\{0,1\}^d$, target $a(x)=\bigoplus_{j=1}^d x_j$, and normalized histories $(I,v)$ where $I\subseteq[d]$ and $v$ assigns bits to all indices in $I$. A world is compatible if $x|_I=v$. A checkpoint is $(I,v,J)$ where $J\subseteq[d]$ is the set of exposed certificate coordinates. Admission is $H=(I,v)$. The partition $P_J$ on the whole history universe equates two histories exactly when their admitted sets agree and the values on the admitted indices in $J$ agree. Explicitly its projection is $(I,v|_{I\cap J})$. Then
$
C(I,v,J)=\{x:x|_{I\cap J}=v|_{I\cap J}\}.
$
Use initially $I=J=\varnothing$ and constant authority throughout. An evidence atom $e_j$ is enabled when $j\notin I$ and adds $j$ to $I$, recording the acquired bit in $v$. For each currently compatible assignment each bit value possible at that source checkpoint has positive support. Both successor values are possible here. This changes $H$ and leaves the partition $P_J$ fixed, so touch is exactly E. A representation atom $r_j$ is enabled when $j\notin J$. It extends $J$ by $j$ and changes neither $H$ nor authority. The extensional partition changes even if $j$ is currently unadmitted: compare two histories with admitted set $\{j\}$ and opposite values in the full carrier. They were equated before and are now distinct. Thus touch of $r_j$ is exactly R. Every atom costs one. The visible checkpoint and outcomes can display the recorded partial assignment and exposed index set, with legal ordinary preconditions given above.

A missing index $j\notin I\cap J$ permits two compatible worlds differing at only $j$, with opposite targets. If $I\cap J=[d]$, the world fiber is a singleton. Consequently any closing branch must execute every $e_j$ and every $r_j$, yielding a lower bound $2d$. A fixed schedule doing each once closes on all supported branches at that cost. Removing every R-touch leaves $J=\varnothing$ and removing every E-touch leaves $I=\varnothing$. Neither permits closure. Freezing authority alone leaves the same cost. The argument realizes order-independent separate necessity as an extensional partition property, including an R refinement performed before the corresponding bit becomes admitted.
