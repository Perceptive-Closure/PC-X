# Counterexamples and retained restrictions

27 November 2026. Each example changes a specific premise of the immutable [candidate seal](STATEMENTS.md).

| Attempted reading | Failure |
| --- | --- |
| A simple opposite pair is necessary for complete-law indistinguishability. | In the first G1 one-read fixture the two equal convex mixtures agree on both measurements. Every simple opposite pair disagrees on both. |
| Opposite pairs that separately match for every deterministic design defeat all randomized designs. | In the second G1 fixture the law of \(A\) matches one negative and \(B\) matches the other. The randomized legal test has worst error \(2/5\). Recombining the matching coordinates invents the negative profile \((1/2,1/2)\). |
| Compactness of the full parameter space suffices for exact finite support at the sign boundary. | Let \(\theta\in[0,1]\), with actual reference defect probability \(\theta\), target cutoff \(1/2\), and one actual diagnostic Bernoulli with mean \(\theta\). The positive side contains the boundary and negative laws approach it. Every mixture of actual negative laws has mean strictly greater than \(1/2\), but \(R_*=1/2\). The same conclusion follows for any fixed finite number of independent Bernoulli reads by continuity. |
| A convexified obstacle provides one actually installed bad world. | The mixtures in G1 witness a lower bound on worst-completion loss. Their common law may be absent from both simple classes. A represented outer cover can add worlds or combinations with no physical realization. |
| Private controller plans are irrelevant even when disclosed to the source. | In the second G1 example, if the responder can see the private draw of the selected probe before installation and switch to that probe's matching negative profile, it can produce a fabricated matching law. This timing changes the class of admissible whole programs. Any permitted announcement of design information belongs in the recorded operative prefix and is included in the complete laws. |
| Binary attainment survives removal of report authority. | If only \(+\) is an authorized report, a realizable negative world has error one even if the available observation perfectly distinguishes the classes. The G1 optimization requires permission to implement both report choices at each used stop. |
| Good sets with strict constraints still yield small finite blockers. | In a one-dimensional simplex with probability coordinate \(p\), require \(p<1\) and \(p\ge1-1/n\) for every \(n\ge2\). Every finite subset is feasible and the whole family is infeasible. G2 retains closed affine inequalities. |
| Pairwise common policy implies joint feasibility. | On three complete policies, require zero probability of choosing policy \(i\) in world \(i\), where its live event is certain and the other two produce a useful output. Every pair of constraints is feasible and their triple is infeasible. The blocker-size claim uses the controller simplex's dimension. |
| Admitting facts and enabling new controls have the same optimization semantics. | A new diagnostic could reveal an otherwise completely hidden target while leaving every old world possible. A library with unchanged \(F_j=W\) cannot hit any existing blocker. Physically enabling the new read changes the complete controller policy set and falls outside G2's fixed-menu selection. |
| Equal pre-report laws or correct reference labels validate the live continuation. | Use identical pre-report rows and identical defect-free reference behavior. One actual responder enables an additional counted live event only after a positive release cue and gives violation with probability one whenever the audit issues. Both worlds remain reference-positive. The audit only predicts the registered target. Physical validity needs separately checked conditional continuation. |
| Whole-attempt risk and selective risk are interchangeable. | In G3 both matched worlds have the same pre-report support. Positive issuance on the positive world gives positive issuance on the negative world, where conditional counted risk is at least \(5/8\). Whole-attempt risk in that negative world can be below \(1/4\) because issuance is rare. |
| An optimal expected tariff bounds every paid path. | G3 attains expected cost \(5/4\). Every feasible policy with the stated mistake and coverage criteria sometimes buys the price-3 read. The supported price cap has its own exact optimum. |

Unbounded stopping and general infinite-record games still need additional topology or a new proof. A source-to-deployment association that leaves actual event semantics or authorities unchecked supplies no quantitative error term for those omissions.
