
# Selected machine-checked supporting lemmas

Run from the exact campaign checkout with Lean 4.21.0 and the standard library.

~~~powershell
lean THEORY-FLAGSHIP-GENERALIZATION/T30-P-GENERALIZED/TransportChecks.lean
lean THEORY-FLAGSHIP-GENERALIZATION/FORMAL-PROOFS/A-StrategicAudit.lean
lean THEORY-FLAGSHIP-GENERALIZATION/FORMAL-PROOFS/U-Selected.lean
~~~

P mechanizes arithmetic for directed matched/residual bounds, monotonic envelope terms and exact signed margins. A checks matched decision, coverage and price implications in integer scaling. U checks scaled optimal price, unmatched risk and tightened constraint arithmetic. The full construction, semantics, general minimax, conditional probability, calibration, complexity and physical implementation use the written proofs.
