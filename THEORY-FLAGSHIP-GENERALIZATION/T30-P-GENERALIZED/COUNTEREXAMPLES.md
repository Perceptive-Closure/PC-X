# G01/G02 · Counterexamples and checked limits

| Targeted weakening | Exact failure |
| --- | --- |
| G01 needs only a fit of independent stochastic margins | The same hidden parameter yields two iid conditional Bernoulli draws with worst true disagreement \(1/2\). Free row choices give one. A finite mixture polytope cannot preserve all affine expectations of their curve of joint probabilities. |
| G01 risk at endpoints bounds interior risk | The true disagreement function attains \(1/2\) at \(\theta=1/2\) and vanishes at both endpoints. A cap \(1/4\) is passed by the endpoint mesh alone. |
| G01 can always output rational probabilities | Rational guard \(2\theta^2\ge1\), \(0\le\theta\le1\), combined with the two legitimate action risk/utility rows in the proof, forces \(x=1/\sqrt2\). |
| G01 failed compact or continuity premises are interchangeable | With policy \(x\in(0,1]\), weak rows \(\theta x\le\theta^2\) for \(\theta\in[0,1]\) have no common point but all finite subsets work. Separately, continuous policy data with compact parameter domain can retain an unattained worldwise supremum when its parameter coefficients jump, as in \(F(\theta)=\theta\) below one and \(F(1)=0\). |
| G01 finite infeasibility witnesses imply finite active-set equality | The same \(\theta x\le\theta^2\) example with compact \(x\in[0,1]\) has exact optimum zero for maximizing \(x\). Every finite subsystem admits positive \(x\). The algebraic feasibility and finite infeasibility receipts answer different questions. |
| G01 can use an approximate mesh for hard callability | A call with probability \(\theta>0\) of changing frozen \(R\) and probability \(1-\theta\) of no change is fully forbidden for every such world. A mesh near or at zero cannot license it. |
| G01 optimistic physical inference from represented infeasibility | Put one actual safe installation in a represented cover with an unrealized installation having no legal useful literal. The cover fails a common positive controller even though the actual installation succeeds. |
| G02 check separately valid fragments and sum them | One vector of mass \(3/4\) in the same cell is verified twice for the same raw tickets. Each is a legitimate subrow, while their sum has mass \(3/2\). Require disjoint portions on each side or a summed domination check. |
| G02 constant per-time visible marginal correspondence | The two visible bits are fair in both sources, perfectly equal in one and always opposite in the other. Conditional rows and trusted event risk differ despite every one-time marginal matching. |
| G02 ignore score decoding on matched outputs | A visible receipt may be identical in both sources, while its true recorded harmful-event indicator is zero in one and one in the other. Matching records and mass one then require a nonzero signed payoff discrepancy. |
| G02 ignore an uncovered deployment stratum | Covered mass \(4/5\) shares a known safe law. The other \(1/5\) may all be harmful in actual deployment. The residual envelope is sharp; replacing that stratum with a nominal safe law is invalid. |
| G02 through a changed intervention | A measurement erases hidden bad state before returning a genuine zero reading. The corresponding unmeasured physical route remains harmful. Report accuracy on the newly written state cannot supply the conditional source relation for the original intervention. |
| G02 carry single-policy evidence across policies | A call \(A\) has identical safe rows in the two sources. Call \(B\) has a nominal safe row and actual always-harmful row. Complete transport for the always-\(A\) policy says nothing about selecting \(B\). |
| G02 discard hard failures on uncovered paths | An unmatched actual observation of mass \(1/100\) leads to a checkpoint where a nominally intended literal is unavailable. A valid controller must take a genuinely available fallback or stop there. No mismatch budget licenses the literal. |
| G02 use matching abstract IDs or authorized aliases as literals | A nominal routine has literal “left-A”; the actual routine offers only “left-B” with no checked implementation. A common abstract “left” observation cannot itself execute either command across both worlds. |
| G02 identify sufficient facts using only eliminated worlds | Fix the fixture's positive report bits in every world while leaving both separately signed fragment certifications unread. The exact world cell never changes when learning the already-expected bit. The missing verified paired mass changes, and the catalog upper/lower bounds pass only after both checks. |
| G02 separate risk and activation envelopes are complete | The source fixture with \(1/10\) genuinely uncovered mass proves selective risk \(3/19\) by its signed event; separate extrema imply only \(3/17\). At the same time a zero-coverage policy could satisfy the homogeneous inequalities if the floor were dropped. |
| G02 independent columns or branches can build an inadmissible world | Full reports \(00\) and \(11\) alone leave both values individually possible for each field. A prospective audit can never receive \(01\), and applying its putative joint fragment prefixes is absent from the authorized class. |
| G02.3 bounded marginals imply calibration | Set every score equal to the same hidden fair bit. Each unconditional mean is \(1/2\), while observations after the first have conditional means zero or one. Every observed average stays distance \(1/2\) from the reference mean. |
| G02.3 nominal moment separation proves a uniform deadline with drift | Let opposite worlds have \(m_+=1/4,m_-=3/4\) and conditional allowed bias \(1/4\). A common stationary Bernoulli mean \(1/2\) is permitted in both. Identical full exact reports and all diagnostic laws then force maximum wrong-or-abstain error at least \(1/2\). |
| G02.3 unconditional confidence bounds selected risk | Activate only on a calibration exception of probability \(\eta\), and let physical violation be certain there. The absolute false-issuance guarantee can hold while selective risk is one. The stated bound permits it exactly. |
| G02.3 a responder can carry untracked reaction across certification | Equal complete evaluation laws can precede a phase cue that makes one installed responder suppress a genuine protective effect. A fresh independently checked conditional deployment law must include the cue and carried state. The stated calibration bound supplies no restriction on the omitted behavior. |
