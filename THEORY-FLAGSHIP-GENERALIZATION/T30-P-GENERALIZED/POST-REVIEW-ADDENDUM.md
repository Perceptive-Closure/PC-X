# G02.2 · Post-review fixed hard guard clarification

The [statement seal](https://github.com/Perceptive-Closure/PC-X/blob/69b137e57300fbd4af3380d254fb9ab32eee32c1/THEORY-FLAGSHIP-GENERALIZATION/T30-P-GENERALIZED/STATEMENTS.md) and [initial proof release](https://github.com/Perceptive-Closure/PC-X/commit/7f8ae35278bf975c7e224fee1566233f594dce0a) remain immutable. The initial proof already establishes the marked support characterization and G01.1's mixed-world guard/performance certificate. G02.2's reference to a blocker drawn from the retained report cell needs the following fixed-domain interpretation when hard authority is still checked on the larger original guard.

Let \(W\) be the fixed hard guard and \(C\subseteq W\) the nonempty retained report cell. For every controller sequence \(\sigma\), use an exact existential query over \(W\) to decide whether some genuine hard failure gives a marked leaf \(t\) with last sequence \(\sigma\) and \(k_w(t)B_w(t)>0\). Here a forbidden invocation uses the formal marker; its chance weight is the genuine prefix weight times one for the marker, with no purported physical result of invoking it. Include either source if both are part of the exact common guard. Let \(Z_W\) be the set of forced zero sequences. Since
\[
B_w(x)=\sum_t k_w(t)B_w(t)x_{\sigma(t)}
\]
has nonnegative terms, vanishing for every \(w\in W\) is equivalent to imposing \(x_\sigma=0\) for \(\sigma\in Z_W\). Thus the same original hard guard can be compiled once as \(X_W=X\cap\{x:x_\sigma=0,\ \sigma\in Z_W\}\), also retaining the independently checked fixed linear restrictions of the candidate class. Exact semialgebraic queries give a finite checkable compilation. An independently certified equivalent fixed polytope works as well. Guard checking and compilation are charged separately from deciding individual cells.

Within \(C\), every world's envelope requirements are closed affine tests on this fixed \(X_W\). If \(X_W\) is nonempty, compactness and the finite convexity argument of G01.1 give at most \(\dim(\operatorname{aff}X_W)+1\le d_X+1\) algebraic worlds in \(C\) whose envelope constraints are jointly infeasible **with the fixed guard included**. Their linear receipt contains the fixed \(X_W\) rows as well as the retained-world rows. If \(X_W\) is already empty, its own infeasibility suffices. A single retained algebraic representative may be included when the catalog interface requires a nonempty group. Additional reads that preserve all the witnesses supply the same fixed guard. The disagreement and refinement pattern argument is therefore unchanged. Guard provenance may refer to \(W\setminus C\), separately from the counted retained-world group. A witness made of world constraints alone must admit such outside-cell worlds explicitly, as in the mixed guard/score statement of G01.1. When the declared hard guard coincides with \(C\), the original per-world hard-and-envelope proof applies.

For the hostile case, one protected record admits a useful, harmless action \(A\) in world \(w_0\) and only a lawful nonactivating stop in \(w_1\). An exact external report leaves \(C=\{w_0\}\). The protected controller selected using this report is still checked at the same protected start across \(W=\{w_0,w_1\}\). The fixed guard gives \(x_A=0\) because action \(A\) is noncallable in \(w_1\). Positive coverage \(1/2\) in \(w_0\) gives \(x_A\ge1/2\). The receipt combines the fixed upper inequality \(x_A\le0\) and the retained-world inequality \(-x_A\le-1/2\). The latter alone is feasible at \(x_A=1\). [Exact replay](CHECKS.md)
